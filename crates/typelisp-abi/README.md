# typelisp-abi

An internal crate of [typelisp](https://github.com/JunSuzukiJapan/typelisp): the calling convention shared by compiled code and the runtime.
It is published only because the `typelisp` crate depends on it, and its API
is not meant to be used directly or kept stable.

[typelisp](https://github.com/JunSuzukiJapan/typelisp) の内部クレートです（コンパイル済みコードとランタイムが共有する呼び出し規約）。
`typelisp` クレートが依存しているので公開していますが、直接使うことは想定しておらず、
API の互換性も保ちません。
