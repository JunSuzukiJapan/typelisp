# typelisp-front

An internal crate of [typelisp](https://github.com/JunSuzukiJapan/typelisp): the type checker, interpreter, module loader and standard library.
It is published only because the `typelisp` crate depends on it, and its API
is not meant to be used directly or kept stable.

[typelisp](https://github.com/JunSuzukiJapan/typelisp) の内部クレートです（型検査器・インタプリタ・モジュールローダ・標準ライブラリ）。
`typelisp` クレートが依存しているので公開していますが、直接使うことは想定しておらず、
API の互換性も保ちません。
