# typelisp-rt-embedded

An internal crate of [typelisp](https://github.com/JunSuzukiJapan/typelisp): the runtime that compiled programs link for a board without an operating system (a microcontroller), as one static library without std.
It is published as part of typelisp, and its API is not meant to be used
directly or kept stable.

[typelisp](https://github.com/JunSuzukiJapan/typelisp) の内部クレートです（OS の無いボード、つまりマイコン向けにコンパイルしたプログラムがリンクするランタイム。std を使わない 1 つの静的ライブラリ）。
typelisp の一部として公開していますが、直接使うことは想定しておらず、
API の互換性も保ちません。
