# typelisp-rt

An internal crate of [typelisp](https://github.com/JunSuzukiJapan/typelisp): the runtime library that compiled programs link.
It is published only because the `typelisp` crate depends on it, and its API
is not meant to be used directly or kept stable.

[typelisp](https://github.com/JunSuzukiJapan/typelisp) の内部クレートです（コンパイルしたプログラムがリンクするランタイムライブラリ）。
`typelisp` クレートが依存しているので公開していますが、直接使うことは想定しておらず、
API の互換性も保ちません。
