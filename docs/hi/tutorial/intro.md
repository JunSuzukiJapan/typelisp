# शुरुआत करना

REPL में एक्सप्रेशन का मूल्यांकन करने से शुरू करके, यह अध्याय क्रम से फ़ंक्शन, वेरिएबल, कंडीशनल, लूप, और सूचियों तथा `Vector`
को कवर करता है। `typl` को कैसे बिल्ड करें, इसके लिए [README.md](../../../README.md) देखें।

## 1. REPL शुरू करना

बिना आर्ग्युमेंट के चलाने पर `typl` REPL (इंटरैक्टिव मोड) में प्रवेश करता है। `typl>` के बाद एक एक्सप्रेशन टाइप करें; उसका
मूल्यांकन तुरंत होता है और उसका मान प्रिंट होता है। `:quit` REPL से बाहर निकलता है।

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

अब से REPL का इनपुट और परिणाम इसी रूप में दिखाए जाएँगे।

## 2. एक्सप्रेशन का मूल्यांकन

typelisp एक Lisp है, इसलिए एक्सप्रेशन को कोष्ठकों में लिखा जाता है और **ऑपरेटर या फ़ंक्शन का नाम सबसे पहले** आता है। आप `(+ 1 2)`
लिखते हैं, `1 + 2` नहीं।

```
typl> (* 2 (+ 3 4))
14
typl> (+ 1 2 3 4)
10
typl> "hello"
"hello"
typl> (upcase "hello")
"HELLO"
```

संख्याएँ इन प्रकारों की होती हैं:

- **पूर्णांक** का टाइप `int` है। उनके आकार की कोई ऊपरी सीमा नहीं है।
- **दशमलव संख्याओं** का टाइप `f64` है। उन्हें दशमलव बिंदु के साथ लिखें, जैसे `1.5` या `2.0`।
- आप किसी गणना में `int` और `f64` को मिला नहीं सकते। `(+ 1 2.0)` एक टाइप त्रुटि है। बदलने के लिए `(as f64 1)` लिखें।

```
typl> (* 123456789012345 123456789012345)
15241578753238669120562399025
typl> (/ 7 2)
3
typl> (/ 7.0 2.0)
3.5
```

दो पूर्णांकों पर `/` भिन्नात्मक भाग हटाकर पूर्णांक देता है (यह Common Lisp की तरह भिन्न नहीं बनाता)। शेषफल के लिए `(mod 7 2)` का
उपयोग करें।

बूलियन मान `true` और `false` हैं।

```
typl> (> 3 2)
true
typl> (and (> 3 2) (< 3 2))
false
```

## 3. फ़ंक्शन परिभाषित करना

फ़ंक्शन `defun` से परिभाषित होते हैं। **आर्ग्युमेंट के टाइप और रिटर्न टाइप हमेशा लिखे जाते हैं।**

```lisp
(defun square ((n int)) int
  (* n n))
```

- `(n int)` का अर्थ है "टाइप `int` का आर्ग्युमेंट `n`"। कई आर्ग्युमेंट हों तो उन्हें सूचीबद्ध करें:
  `((a int) (b int))`।
- आर्ग्युमेंट सूची के बाद का `int` रिटर्न टाइप है।
- बॉडी के अंतिम एक्सप्रेशन का मान फ़ंक्शन का रिटर्न मान होता है। आप `return` नहीं लिखते।

```
typl> (defun square ((n int)) int (* n n))
typl> (square 12)
144
typl> (square "a")
error: <stdin>:1:9: type error: type mismatch: expected `int`, found `string`
```

जिस कॉल में टाइप मेल नहीं खाते, उसे **चलने से पहले** ही टाइप त्रुटि के रूप में रिपोर्ट किया जाता है। फ़ाइल चलाते समय, कहीं भी एक
टाइप त्रुटि होने पर प्रोग्राम की एक भी पंक्ति नहीं चलती।

किसी आर्ग्युमेंट को वैकल्पिक बनाने के लिए `&optional` का उपयोग करें। यदि आप डिफ़ॉल्ट मान देते हैं, तो आर्ग्युमेंट छोड़ने पर वह वही मान लेता है।

```lisp
(defun greet ((name string) &optional (greeting string "Hello")) string
  (format false "~a, ~a!" greeting name))
```

```
typl> (greet "Ann")
"Hello, Ann!"
typl> (greet "Ann" "Hi")
"Hi, Ann!"
```

`format` के पहले आर्ग्युमेंट के रूप में दिया गया `false` का अर्थ है "परिणाम को प्रिंट करने के बजाय स्ट्रिंग के रूप में लौटाओ"। हर `~a` की जगह
अगला आर्ग्युमेंट आ जाता है।

## 4. वेरिएबल

लोकल वेरिएबल `let` से बनते हैं।

```lisp
(defun sum-of-squares ((a int) (b int)) int
  (let ((aa (square a))
        (bb (square b)))
    (+ aa bb)))
```

- `let` वेरिएबल का टाइप उसके प्रारंभिक मान से लिया जाता है। आपको उसे लिखने की ज़रूरत नहीं।
- एक `let` के वेरिएबल एक-दूसरे का संदर्भ नहीं ले सकते। एक वेरिएबल को उससे पहले वाले वेरिएबल से बनाने के लिए `let*` का उपयोग करें।

```
typl> (let* ((a 1) (b (+ a 1))) (* a b))
2
```

वेरिएबल का मान बदलने के लिए `setf` का उपयोग करें। **असाइनमेंट वेरिएबल का टाइप नहीं बदल सकता।**

```
typl> (let ((x 1)) (setf x "a"))
error: <stdin>:1:22: type error: type mismatch: expected `int`, found `string`
```

ग्लोबल वेरिएबल `defvar` से परिभाषित होते हैं। यहाँ आप टाइप लिखते हैं।

```lisp
(defvar (counter int) 0)
```

## 5. कंडीशनल

### if

`(if condition then-expression else-expression)` लिखें। **else एक्सप्रेशन छोड़ा नहीं जा सकता।**

```lisp
(defun sign ((n int)) string
  (if (< n 0) "negative" "non-negative"))
```

- केवल `bool` टाइप का एक्सप्रेशन ही शर्त हो सकता है। `(if 0 ...)` की तरह संख्या लिखना टाइप त्रुटि है।
- then और else एक्सप्रेशन का टाइप समान होना चाहिए।

जब शर्त झूठ होने पर कुछ नहीं करना हो, तो `when` का उपयोग करें (और उलटे के लिए `unless`)।

```lisp
(defun report-size ((n int)) ()
  (when (> n 100)
    (println "large")
    (println "really large")))
```

### cond

तीन या अधिक शर्तों के लिए `cond` बेहतर पढ़ा जाता है। अंतिम `else` तब लिया जाता है जब कोई भी शर्त पूरी न हो।

```lisp
(defun describe-number ((n int)) string
  (cond ((< n 0) "negative")
        ((= n 0) "zero")
        ((< n 10) "small")
        (else "large")))
```

### match

मान के आकार के आधार पर शाखा बनाने के लिए `match` का उपयोग करें।

```lisp
(defun day-name ((d int)) string
  (match d
    (0 "Sun")
    (6 "Sat")
    (_ "weekday")))
```

`_` किसी भी मान से मेल खाता है। चूँकि `int` के असंख्य मान हैं, `_` वाली शाखा छोड़ना एक त्रुटि है, जो बताती है कि सभी स्थितियाँ कवर नहीं
हुई हैं। `match` की असली ताकत `Option` और आपके अपने परिभाषित टाइप को खोलकर देखने में है, जो अगले अध्याय [टाइप की बुनियादी बातें](types.md) में आएँगे।

## 6. लूप

एक फ़ंक्शन स्वयं को कॉल कर सकता है।

```lisp
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))
```

```
typl> (fact 30)
265252859812191058636308480000000
```

निश्चित संख्या में दोहराने के लिए `dotimes` का उपयोग करें। `i` 0 से `n - 1` तक जाता है।

```lisp
(defun sum-to ((n int)) int
  (let ((total 0))
    (dotimes (i (+ n 1))
      (setf total (+ total i)))
    total))
```

```
typl> (sum-to 100)
5050
```

`while`, `do`, और Common Lisp का विस्तृत `loop` भी हैं। विस्तृत `loop` के क्लॉज़ शब्द कीवर्ड के रूप में लिखे जाते हैं (`:for`, `:collect`
आदि)।

```
typl> (loop :for i :from 1 :to 5 :collect (* i i))
#<vector<int> 1 4 9 16 25>
```

## 7. सूचियाँ और Vector

### Vector

समान टाइप के मानों का क्रम रखने के लिए `Vector<T>` का उपयोग करें। `T` तत्वों का टाइप है।

```lisp
(let ((v (the Vector<int> (Vector::new))))
  (push v 3)
  (push v 1)
  (push v 2)
  (println "~a" v))
;; यह #<vector<int> 3 1 2> प्रिंट करता है
```

- अकेला `(Vector::new)` तत्वों का टाइप तय नहीं करता, इसलिए `(the Vector<int> ...)` से टाइप दें।
- `(push v x)` अंत में जोड़ता है, `(get v i)` तत्व `i` पढ़ता है, और `(len v)` लंबाई देता है।
- सीमा से बाहर के इंडेक्स वाला `get` प्रोग्राम को त्रुटि के साथ रोक देता है।

### lambda और उच्च-क्रम फ़ंक्शन

अनाम फ़ंक्शन `lambda` से बनते हैं। `defun` की तरह, आप आर्ग्युमेंट और रिटर्न टाइप लिखते हैं।

```
typl> ((lambda ((x int)) int (* x 2)) 21)
42
```

`map`, `filter`, `sort`, `foldl` और उनके साथी `(iter v)` से **इटरेटर** में बदले गए `Vector` को लेते हैं। कलेक्शन
पहले आता है और फ़ंक्शन दूसरे स्थान पर। ऊपर का `v` `let` से बाँधा गया था, इसलिए उस `let` के बाहर उसका उपयोग नहीं
किया जा सकता। अगला उदाहरण पहले `defvar` से `v` परिभाषित करता है।

```lisp
(defvar (v Vector<int>) (Vector::new))
(push v 3)
(push v 1)
(push v 2)

(map (iter v) (lambda ((x int)) int (* x 10)))                 ; => #<vector<int> 30 10 20>
(filter (iter v) (lambda ((x int)) bool (> x 1)))              ; => #<vector<int> 3 2>
(sort (iter v) (lambda ((a int) (b int)) bool (< a b)))        ; => #<vector<int> 1 2 3>
(foldl (iter v) (lambda ((acc int) (x int)) int (+ acc x)) 0)  ; => 6
```

तत्वों को एक-एक करके प्रोसेस करने के लिए `doiter` का उपयोग करें।

```lisp
(doiter (x (iter v))
  (println "item ~a" x))
```

जो फ़ंक्शन किसी फ़ंक्शन को आर्ग्युमेंट के रूप में लेता है, वह उस आर्ग्युमेंट का टाइप `(fn (argument-types...) return-type)` के रूप में लिखता है।
`defun` से परिभाषित फ़ंक्शन को उसके नाम से मान की तरह पास किया जा सकता है।

```lisp
(defun twice ((f (fn (int) int)) (x int)) int
  (f (f x)))

(twice square 3)                                ; => 81
(twice (lambda ((x int)) int (* x 3)) 2)        ; => 18
```

### सूचियाँ (S-एक्सप्रेशन)

`'(1 2 3)` या `(list 1 2 3)` से बनी सूचियाँ **S-एक्सप्रेशन डेटा** हैं। उनके तत्वों का एक ही टाइप होना ज़रूरी नहीं।

```
typl> '(1 2 3)
(1 2 3)
typl> (list 1 "two" 'three)
(1 "two" three)
```

S-एक्सप्रेशन डेटा मुख्य रूप से प्रोग्रामों को स्वयं संभालने के लिए है, macro ([Macro](macros.md)) में और `read` के साथ। जिस डेटा के तत्वों का टाइप ज्ञात हो, उसके लिए
`Vector<T>` का उपयोग करें। S-एक्सप्रेशन सूची पर `dolist` से चला जा सकता है।

```lisp
(dolist (x '(1 2 3))
  (println "x=~a" x))
```

दो मानों की जोड़ी `cons` से बनती है और `car` तथा `cdr` से खोली जाती है।

```
typl> (let ((p (cons "age" 42))) (cdr p))
42
```

## 8. फ़ाइल में प्रोग्राम लिखना

प्रोग्राम को फ़ाइल में (एक्सटेंशन `.typl` के साथ) लिखकर `typl file-name` से चलाया जा सकता है। परिणाम दिखाने के लिए `println` का उपयोग करें।

```lisp
;; hello.typl
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))

(dotimes (i 5)
  (println "~a! = ~a" i (fact i)))
```

```sh
$ typl hello.typl
0! = 1
1! = 1
2! = 2
3! = 6
4! = 24
```

- `println` उन्हीं निर्देशों के साथ प्रिंट करता है जो `format` में हैं और अंत में नई पंक्ति जोड़ता है। `print` नई पंक्ति नहीं जोड़ता।
- `~a` मान को मानव-पठनीय रूप में डालता है, और `~s` ऐसे रूप में जिसे वापस पढ़ा जा सके (स्ट्रिंग को उनके `"` मिलते हैं)।
- फ़ाइल ऊपर से नीचे पढ़ी जाती है। **किसी फ़ंक्शन को उसकी परिभाषा से पहले कॉल नहीं किया जा सकता।**
