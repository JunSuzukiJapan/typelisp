# البدء السريع

بدءًا من تقييم التعبيرات في الـ REPL يتناول هذا الفصل بالترتيب الدوال والمتغيرات والشروط والحلقات
والقوائم و`Vector`. وللاطلاع على طريقة بناء `typl` راجع [README.md](../../../README.md).

## 1. تشغيل الـ REPL

عند تشغيل `typl` بلا وسائط يدخل الـ REPL (الوضع التفاعلي). اكتب تعبيرًا بعد `typl>` فيُقيَّم في الحال
وتُطبع قيمته. ويغادر `:quit` الـ REPL.

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

ومن هنا فصاعدًا يُعرض الدخل والنتائج في الـ REPL بهذه الصورة.

## 2. تقييم التعبيرات

typelisp لغة Lisp، فيُحاط التعبير بأقواس مع **وضع المعامِل أو اسم الدالة أولًا**. تكتب `(+ 1 2)` وليس
`1 + 2`.

```
typl> (* 2 (+ 3 4))
14
typl> (+ 1 2 3 4)
10
typl> "hello"
"hello"
typl> (upcase "hello")
"HELLO"
```

للأعداد هذه الأنواع:

- **الأعداد الصحيحة** نوعها `int`. ولا يوجد حد أعلى لحجمها.
- **الأعداد العشرية** نوعها `f64`. تُكتب بفاصلة عشرية كما في `1.5` أو `2.0`.
- لا يمكن خلط `int` و`f64` في عملية حسابية. فـ `(+ 1 2.0)` خطأ في الأنواع. وللتحويل اكتب
  `(as f64 1)`.

```
typl> (* 123456789012345 123456789012345)
15241578753238669120562399025
typl> (/ 7 2)
3
typl> (/ 7.0 2.0)
3.5
```

القسمة `/` على عددين صحيحين تعطي عددًا صحيحًا بإسقاط الجزء الكسري (ولا تنتج كسرًا كما في Common Lisp).
واستخدم `(mod 7 2)` للباقي.

القيمتان المنطقيتان هما `true` و`false`.

```
typl> (> 3 2)
true
typl> (and (> 3 2) (< 3 2))
false
```

## 3. تعريف الدوال

تُعرَّف الدوال بـ `defun`. **تُكتب أنواع الوسائط والنوع الراجع دائمًا.**

```lisp
(defun square ((n int)) int
  (* n n))
```

- `(n int)` تعني "وسيط `n` من النوع `int`". ومع عدة وسائط اسردها: `((a int) (b int))`.
- `int` بعد قائمة الوسائط هو النوع الراجع.
- قيمة آخر تعبير في الجسم هي القيمة التي تعيدها الدالة. ولا تكتب `return`.

```
typl> (defun square ((n int)) int (* n n))
typl> (square 12)
144
typl> (square "a")
error: <stdin>:1:9: type error: type mismatch: expected `int`, found `string`
```

يُبلَّغ عن الاستدعاء الذي لا تتطابق أنواعه بوصفه خطأ في الأنواع **قبل أن يعمل**. وعند تشغيل ملف فإن خطأ
واحدًا في الأنواع في أي مكان يعني ألا يعمل أي سطر من البرنامج.

ولجعل وسيط اختياريًا استخدم `&optional`. وإذا أعطيت قيمة افتراضية أخذ الوسيط تلك القيمة عند حذفه.

```lisp
(defun greet ((name string) &optional (greeting string "Hello")) string
  (format false "~a, ~a!" greeting name))
```

```
typl> (greet "Ann")
"Hello, Ann!"
typl> (greet "Ann" "Hi")
"Hi, Ann!"
```

الـ `false` المعطاة وسيطًا أول لـ `format` تعني "أعد النتيجة سلسلة نصية بدلًا من طباعتها". ويُستبدل كل
`~a` بالوسيط التالي.

## 4. المتغيرات

تُنشأ المتغيرات المحلية بـ `let`.

```lisp
(defun sum-of-squares ((a int) (b int)) int
  (let ((aa (square a))
        (bb (square b)))
    (+ aa bb)))
```

- يؤخذ نوع متغير `let` من قيمته الابتدائية. ولا حاجة إلى كتابته.
- لا يمكن لمتغيرات `let` الواحدة أن يشير بعضها إلى بعض. ولبناء متغير من المتغير الذي قبله استخدم `let*`.

```
typl> (let* ((a 1) (b (+ a 1))) (* a b))
2
```

ولتغيير قيمة متغير استخدم `setf`. **لا يمكن للإسناد أن يغيّر نوع المتغير.**

```
typl> (let ((x 1)) (setf x "a"))
error: <stdin>:1:22: type error: type mismatch: expected `int`, found `string`
```

تُعرَّف المتغيرات العامة بـ `defvar`. وهنا تكتب النوع فعلًا.

```lisp
(defvar (counter int) 0)
```

## 5. الشروط

### if

اكتب `(if الشرط تعبير-then تعبير-else)`. **لا يمكن حذف تعبير else.**

```lisp
(defun sign ((n int)) string
  (if (< n 0) "negative" "non-negative"))
```

- لا يصلح شرطًا إلا تعبير من النوع `bool`. وكتابة عدد كما في `(if 0 ...)` خطأ في الأنواع.
- يجب أن يكون لتعبيري then وelse النوع نفسه.

وعندما لا ينبغي أن يحدث شيء في حالة الخطأ (false) استخدم `when` (و`unless` للعكس).

```lisp
(defun report-size ((n int)) ()
  (when (> n 100)
    (println "large")
    (println "really large")))
```

### cond

مع ثلاثة شروط أو أكثر تكون `cond` أوضح قراءة. ويؤخذ `else` الأخير عندما لا يتحقق أي من الشروط.

```lisp
(defun describe-number ((n int)) string
  (cond ((< n 0) "negative")
        ((= n 0) "zero")
        ((< n 10) "small")
        (else "large")))
```

### match

للتفرع بحسب شكل قيمة استخدم `match`.

```lisp
(defun day-name ((d int)) string
  (match d
    (0 "Sun")
    (6 "Sat")
    (_ "weekday")))
```

يطابق `_` أي قيمة. ولأن `int` له قيم لا حصر لها فإن حذف فرع `_` خطأ يقول إن الحالات غير مغطاة كلها.
أما موضع تألق `match` الحقيقي فهو تفكيك `Option` والأنواع التي تعرّفها بنفسك، وهي موضوع الفصل التالي
[أساسيات الأنواع](types.md).

## 6. الحلقات

يمكن للدالة أن تستدعي نفسها.

```lisp
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))
```

```
typl> (fact 30)
265252859812191058636308480000000
```

لعدد ثابت من التكرارات استخدم `dotimes`. وتمرّ `i` من 0 إلى `n - 1`.

```lisp
(defun sum-to ((n int)) int
  (let ((total 0))
    (dotimes (i (+ n 1))
      (setf total (+ total i)))
    total))
```

```
typl> (sum-to 100)
5050
```

وتوجد أيضًا `while` و`do` و`loop` الموسّعة من Common Lisp. وتُكتب كلمات بنود `loop` الموسّعة على صورة
كلمات مفتاحية (`:for` و`:collect` وهكذا).

```
typl> (loop :for i :from 1 :to 5 :collect (* i i))
#(1 4 9 16 25)
```

## 7. القوائم و Vector

### Vector

لحمل تسلسل من قيم من النوع نفسه استخدم `Vector<T>`. و`T` هو نوع العنصر.

```lisp
(let ((v (the Vector<int> (Vector::new))))
  (push v 3)
  (push v 1)
  (push v 2)
  (println "~a" v))
;; تطبع #(3 1 2)
```

- لا تحدد `(Vector::new)` وحدها نوع العنصر، فأعطِ النوع بـ `(the Vector<int> ...)`.
- `(push v x)` تضيف في النهاية، و`(get v i)` تقرأ العنصر `i`، و`(len v)` تعطي الطول.
- `get` بفهرس خارج النطاق توقف البرنامج بخطأ.

### lambda والدوال عالية الرتبة

تُصنع الدوال المجهولة بـ `lambda`. وكما في `defun` تكتب أنواع الوسائط والنوع الراجع.

```
typl> ((lambda ((x int)) int (* x 2)) 21)
42
```

تأخذ `map` و`filter` و`sort` و`foldl` وأخواتها `Vector` محوَّلًا إلى **مكرِّر (iterator)** بـ `(iter v)`.
وتأتي المجموعة أولًا والدالة ثانيًا. و`v` أعلاه مربوط بـ `let`، فلا يمكن استخدامه خارج ذلك `let`. لذا
يعرّف المثال التالي `v` أولًا بـ `defvar`.

```lisp
(defvar (v Vector<int>) (Vector::new))
(push v 3)
(push v 1)
(push v 2)

(map (iter v) (lambda ((x int)) int (* x 10)))                 ; => #(30 10 20)
(filter (iter v) (lambda ((x int)) bool (> x 1)))              ; => #(3 2)
(sort (iter v) (lambda ((a int) (b int)) bool (< a b)))        ; => #(1 2 3)
(foldl (iter v) (lambda ((acc int) (x int)) int (+ acc x)) 0)  ; => 6
```

ولمعالجة العناصر واحدًا واحدًا استخدم `doiter`.

```lisp
(doiter (x (iter v))
  (println "item ~a" x))
```

الدالة التي تأخذ دالة وسيطًا تكتب نوع ذلك الوسيط على الصورة `(fn (أنواع-الوسائط...) النوع-الراجع)`.
والدالة المعرَّفة بـ `defun` يمكن تمريرها باسمها كقيمة.

```lisp
(defun twice ((f (fn (int) int)) (x int)) int
  (f (f x)))

(twice square 3)                                ; => 81
(twice (lambda ((x int)) int (* x 3)) 2)        ; => 18
```

### القوائم (التعبيرات الرمزية)

القوائم المصنوعة بـ `'(1 2 3)` أو `(list 1 2 3)` هي **بيانات تعبيرات رمزية (S-expressions)**. ولا يلزم أن
تشترك عناصرها في نوع واحد.

```
typl> '(1 2 3)
(1 2 3)
typl> (list 1 "two" 'three)
(1 "two" three)
```

بيانات التعبيرات الرمزية مخصصة أساسًا للتعامل مع البرامج نفسها، في الماكرو ([الماكرو](macros.md)) ومع
`read`. أما للبيانات التي نوع عناصرها معروف فاستخدم `Vector<T>`. ويمكن المرور على قائمة تعبير رمزي بـ
`dolist`.

```lisp
(dolist (x '(1 2 3))
  (println "x=~a" x))
```

يُصنع زوج من قيمتين بـ `cons` ويُفكَّك بـ `car` و`cdr`.

```
typl> (let ((p (cons "age" 42))) (cdr p))
42
```

## 8. كتابة برنامج في ملف

يمكن كتابة برنامج في ملف (بالامتداد `.typl`) وتشغيله بـ `typl اسم-الملف`. استخدم `println` لعرض النتائج.

```lisp
;; hello.typl
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))

(dotimes (i 5)
  (println "~a! = ~a" i (fact i)))
```

```sh
$ typl hello.typl
0! = 1
1! = 1
2! = 2
3! = 6
4! = 24
```

- تطبع `println` باستخدام موجِّهات `format` نفسها وتنتهي بسطر جديد. أما `print` فلا تضيف السطر
  الجديد.
- يضمّن `~a` قيمة بصورة مقروءة للإنسان، و`~s` بصورة يمكن قراءتها من جديد (فتأخذ السلاسل النصية علامتي
  `"`).
- يُقرأ الملف من الأعلى إلى الأسفل. **ولا يمكن استدعاء دالة قبل تعريفها.**
