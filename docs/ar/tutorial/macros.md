# الماكرو (Macros)

الماكرو دالة تأخذ برنامجًا وتعيد برنامجًا. وتتيح لك الماكرو ابتكار صياغة جديدة لا تستطيع الدوال التعبير
عنها. وتعمل ماكرو typelisp بالطريقة نفسها التي يعمل بها `defmacro` في Common Lisp. يفترض هذا الفصل أنك
قرأت "القوائم (التعبيرات الرمزية)" في [البدء السريع](intro.md).

## 1. كيف تختلف الماكرو عن الدوال

تستلم الدالة وسائطها **بعد تقييمها**. أما الماكرو فتستلمها **على صورة تعبيرات قبل التقييم** (كبيانات
تعبيرات رمزية S-expression)، وتبني تعبيرًا آخر وتعيده. ويحل التعبير المُعاد محل استدعاء الماكرو، ولا
يُفحص نوعه ولا يُشغَّل إلا بعد ذلك. ويسمى هذا الإحلال **التوسيع (expansion)**.

فمثلًا لا يمكن كتابة صياغة مثل `unless` كدالة. فكدالة سيُقيَّم الجسم أولًا حتى عندما يكون الشرط صحيحًا.

## 2. `defmacro` والاقتباس الجزئي (quasiquote)

لنصنع `my-unless` التي تشغّل جسمها فقط عندما يكون الشرط خاطئًا.

```lisp
(defmacro my-unless (test &rest body)
  `(if ,test () (progn ,@body ())))
```

- لا تُكتب أنواع لوسائط الماكرو. فكل وسيط بيانات تعبير رمزي.
- يستلم `&rest body` الوسائط المتبقية معًا في قائمة واحدة.
- يُبنى التعبير الذي يبدأ بـ `` ` `` (الاقتباس الجزئي) كبيانات كما هو مكتوب. وداخله:
  - `,test` تُدرج محتويات المتغير `test` في ذلك الموضع.
  - `,@body` تُدمج عناصر القائمة `body` في ذلك الموضع.

```lisp
(my-unless (> 1 2)
  (println "one")
  (println "two"))
;; one
;; two
```

يمكنك التحقق من التوسيع بـ `macroexpand-1`. وعند كتابة ماكرو فإن النظر في توسيعها أولًا هو أسرع سبيل
للتقدم.

```
typl> (macroexpand-1 '(my-unless (> 1 2) (println "one")))
(ok (if (> 1 2) () (progn (println "one") ())))
```

## 3. تُفحص أنواع التوسيعات أيضًا

يُفحص نوع التعبير الذي تعيده الماكرو مثل أي تعبير تكتبه بيدك.

```
typl> (defmacro add-a (x) `(+ ,x "a"))
typl> (add-a 1)
error: <stdin>:1:1: type error: type mismatch: expected `int`, found `string`
```

يُبلَّغ عن الخطأ في الموضع الذي استُدعيت فيه الماكرو.

وتنطبق على التوسيعات كما هي القاعدتان القائلتان إن فرع else في `if` لا يمكن حذفه وإن فرعي `if` يجب أن
يكون لهما النوع نفسه. ولذلك تنتهي `my-unless` أعلاه بـ `(progn ,@body ())` ليكون لفرعي `if` النوع `()`
مهما كان نوع آخر تعبير في الجسم.

## 4. تضارب الأسماء و`gensym`

ماكرو مباشرة تبدّل قيمتي متغيرين تبدو هكذا:

```lisp
(defmacro swap-bad (a b)
  `(let ((tmp ,a))
     (setf ,a ,b)
     (setf ,b tmp)))
```

تعمل في معظم الأحيان، لكنها تنكسر عندما يتصادف أن يكون اسم متغير المستدعي `tmp`.

```lisp
(let ((tmp 1) (other 2))
  (swap-bad tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=1 other=2   (لم تُبدَّل)
```

التوسيع هو `(let ((tmp tmp)) (setf tmp other) (setf other tmp))`، فيحجب `tmp` الذي صنعته الماكرو
`tmp` الخاص بالمستدعي.

ولتجنب ذلك أنشئ أسماء المتغيرات المستخدمة داخل الماكرو بـ `gensym`. وتعيد `gensym` رمزًا جديدًا لا يمكن
كتابته في أي موضع من برنامج.

```lisp
(defmacro swap (a b)
  (let ((tmp (gensym "tmp")))
    `(let ((,tmp ,a))
       (setf ,a ,b)
       (setf ,b ,tmp))))
```

```lisp
(let ((tmp 1) (other 2))
  (swap tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=2 other=1
```

وكما في Common Lisp لا تمنع ماكرو typelisp تضارب الأسماء تلقائيًا (فهي غير صحية unhygienic). فتذكّر:
**استخدم `gensym` للربطات التي تنشئها الماكرو.**

وبالطريقة نفسها يمكن كتابة ماكرو تكرر جسمها عددًا معينًا من المرات هكذا:

```lisp
(defmacro repeat (n &rest body)
  (let ((i (gensym "i")))
    `(dotimes (,i ,n) ,@body)))

(repeat 3 (println "hi"))
```

## 5. التوسيع بشكل مختلف بحسب الوسائط

جسم الماكرو شيفرة typelisp عادية، فيمكنه فحص وسائطه بـ `if` أو `match` وبناء توسيع مختلف. والوسائط بيانات
تعبيرات رمزية (`Option<Sexpr>`)، والقائمة الفارغة هي `none`.

لنصنع `my-and` التي تعيد `true` إذا كانت كل شروطها صحيحة.

```lisp
(defmacro my-and (&rest forms)
  (match forms
    ((none) 'true)                                    ; لا وسائط
    ((cons f more)
     (if (sexpr-null more)
         f                                            ; واحد فقط
         `(if ,f (my-and ,@more) false)))             ; اثنان أو أكثر
    (_ (panic "my-and: not a list"))))

(my-and (> 2 1) (> 3 2))      ; => true
(my-and (> 2 1) (> 1 3))      ; => false
```

- `(cons f more)` نمط يأخذ رأس القائمة في `f` وباقيها في `more`.
- تختبر `sexpr-null` ما إذا كانت بيانات التعبير الرمزي قائمة فارغة.
- فرع `_` الأخير لازم لأن لبيانات التعبيرات الرمزية صورًا غير القوائم (أعداد وسلاسل نصية وهكذا)، ويتطلب
  `match` تغطيتها أيضًا. ووسيط `&rest` قائمة دائمًا، فهذا الفرع لا يعمل فعليًا أبدًا.
- يمكن للماكرو أن تستدعي نفسها في توسيعها. ويتكرر التوسيع حتى لا يبقى أي استدعاء ماكرو.

## 6. الوسائط الاختيارية

يستلم `&optional` وسائط يمكن حذفها. ويمكن إعطاء قيم افتراضية.

```lisp
(defmacro inc-by (place &optional (n 1))
  `(setf ,place (+ ,place ,n)))

(let ((c 10))
  (inc-by c)
  (inc-by c 5)
  c)                            ; => 16
```

يستلم `&key` وسائط بالكلمات المفتاحية
([مرجع الصياغة 3.14](../reference/syntax.md#314-defmacro--تعريف-الماكرو)).

## 7. `macrolet`: ماكرو لموضع واحد فقط

يمكن تعريف ماكرو لا تُستخدم إلا داخل تعبير واحد بـ `macrolet`. وهي غير مرئية في الخارج.

```lisp
(macrolet ((sq (x) `(* ,x ,x)))
  (+ (sq 3) (sq 4)))            ; => 25
```

## 8. أمور ينبغي تذكرها

- **لا يمكن استدعاء الماكرو إلا بعد تعريفها.** وكما مع الدوال عرّفها قرب أعلى الملف.
- اجعل الماكرو متاحة للوحدات الأخرى بـ `(pub defmacro ...)`.
- كثير من الصياغة القياسية، ومنها `when` و`unless` و`cond` و`and` و`or` و`dotimes`، معرَّف على أنه ماكرو.
  ويمكنك رؤية ما بداخلها بـ `(macroexpand '(when true 1))`.
- إذا أمكن كتابة شيء كدالة فاكتبه دالة. فالماكرو لا يمكن تمريرها كقيم، وعليك قراءة توسيعها لتفهم ما
  تفعله.
