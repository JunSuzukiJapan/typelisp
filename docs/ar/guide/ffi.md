# واجهة C الخارجية (defffi)

يشرح هذا الدليل كيفية استدعاء دوال C من typelisp. وقائمة الأنواع التي يمكن إعلانها والقيود موجودة في
[مرجع الصياغة 3.3](../reference/syntax.md#33-defffi--إعلان-دوال-c-ffi).

## 1. الإعلان عن دالة واستدعاؤها

يعلن `defffi` اسم دالة C وأنواعها.

```lisp
(defffi (c-getpid "getpid") () i32)            ; اسم typelisp واسم رمز C
(defffi (c-strlen "strlen") (string) c-ulong)
(defffi (c-cos "cos") (f64) f64 :library "m")  ; يُبحث عنها في libm
```

تُغلَّف الاستدعاءات بـ `(unsafe ...)`.

```lisp
(unsafe (c-getpid))        ; => 12345
(unsafe (c-cos 0.0))       ; => 1.0
```

`unsafe` لازمة لأن المترجم لا يستطيع التحقق من أن الأنواع المعلنة تطابق الأنواع الحقيقية في جانب C.
وكتابة `unsafe` تعني أنك أنت الكاتب تتحمل مسؤولية هذا التحقق. ونسيانها يعطي خطأ يشرح ذلك.

## 2. كتابة غلاف آمن

الاستخدام المقصود هو حصر `unsafe` في موضع واحد وتقديم دالة عادية إلى الخارج.

```lisp
(defun pid () i32 (unsafe (c-getpid)))
(defun str-len ((s string)) int (as int (unsafe (c-strlen s))))

(pid)              ; لا يحتاج المستدعي إلى unsafe
(str-len "hello")  ; => 5
```

## 3. كيف تتقابل الأنواع

| typelisp | C |
|---|---|
| `i8` `i16` `i32` / `u8` `u16` `u32` | أعداد صحيحة بالعرض نفسه |
| `f32` / `f64` | `float` / `double` |
| `bool` | `bool` (`_Bool`) |
| `()` | `void` |
| `string` | `const char *` |
| `c-long` / `c-ulong` | `long` / `unsigned long` (وكذلك `size_t` و`int64_t` وما إلى ذلك) |
| `ptr` | أي مؤشر (`void *` و`FILE *` وما إلى ذلك) |
| `(ptr T)` | مؤشر إلى `T` ([القسم 7](#7-بنى-c)) |

### السلاسل النصية

- تُنسخ `string` التي تمررها إلى سلسلة C منتهية بـ NUL، وتُحرَّر بعد عودة الاستدعاء. ووجود NUL في وسط
  السلسلة خطأ.
- ونتيجة الدالة التي تعيد `string` تُنسخ أيضًا. ولا تُحرَّر ذاكرة جانب C. وبالنسبة إلى الدوال التي
  تعيد سلسلة يجب على المستدعي تحريرها (مثل `strdup`) خذ النتيجة على أنها `ptr` وحرّرها بنفسك بـ `free`.
- إذا أعادت دالة معلَنة بأنها تعيد `string` قيمة NULL فهذا خطأ. خذ نتيجة الدوال التي قد تعيد NULL (مثل
  `getenv`) على أنها `ptr`.

### `c-long` / `c-ulong` / `ptr`

هذه الأنواع موجودة فقط لتمرير القيم عبر الحدود مع C، و**لا تدعم أي عمليات حسابية**. ولاستخدام أحدها
كعدد صحيح في typelisp حوّله بـ `as`.

```lisp
(as int (unsafe (c-strlen s)))      ; لا يفقد int أي شيء من القيمة ذات 64 بت
(try-as i32 (unsafe (c-strlen s)))  ; none إذا لم تتسع في i32
(unsafe (c-malloc 16))              ; يمكن تمرير الثوابت الصحيحة كما هي
```

و`ptr` قيمة تُسلَّم من جديد إلى دوال C. ولا توجد طريقة لقراءة ما تشير إليه من جانب typelisp.

```lisp
(defffi (c-malloc "malloc") (c-ulong) ptr)
(defffi (c-free "free") (ptr) ())

(unsafe (let ((p (c-malloc 16)))
          (c-free p)
          ()))
```

لا يمكن أن تظهر هذه الأنواع إلا كوسائط دوال وقيم راجعة ومتغيرات محلية. ولا يمكن أن تكون حقول بنى
ولا متغيرات عامة ولا وسائط نوع لـ `Vector` ونحوه.

## 4. تسمية مكتبة

بدون `:library` يُبحث عن الرمز فيما هو مربوط بالفعل بالعملية (libc ونحوها). أما الدوال من مكتبات أخرى
فتحتاج `:library`.

```lisp
(defffi (sqlite-version "sqlite3_libversion") () string :library "sqlite3")
```

- يُبحث عن الاسم القصير مثل `"sqlite3"` على أنه `libsqlite3.dylib` ثم `libsqlite3.so`.
- الاسم الذي يحتوي على `/` يُعامَل كمسار.
- إذا لم يُعثر على الرمز المعلَن فإن الخطأ يذكره بالاسم.

## 5. ترجمة AOT

يمكن تحويل البرامج التي تستخدم `defffi` إلى ملفات تنفيذية بـ
[`compile-file`](compile.md#3-بناء-ملف-تنفيذي-بالترجمة-المسبقة-aot) كما هي. وتُضاف المكتبات المسمّاة بـ
`:library` وقت الربط تلقائيًا، فلا تحتاج `compile-file` إلى وسائط إضافية.

## 6. الاستدعاءات الراجعة (Callbacks)

يمكنك تمرير دالة typelisp إلى دالة C لتستدعيها C راجعةً. اكتب نوع دالة بين أنواع وسائط `defffi`، وعند
الاستدعاء ضع في ذلك الموضع اسم دالة أو تعبير `lambda`.

```lisp
(defffi (c-free "free") (ptr) ())
(defffi (c-strdup "strdup") (string) ptr)
(defffi (c-strncmp "strncmp") (ptr ptr c-ulong) i32)
(defffi (text-of "strstr") (ptr string) string)          ; strstr(p, "") تعيد p
(defffi (c-qsort "qsort") (ptr c-ulong c-ulong (fn (ptr ptr) i32)) ())

(defun sort-chars ((s string)) string
  (unsafe
    (let ((buf (c-strdup s)))
      (c-qsort buf (as c-ulong (length s)) 1
               (lambda ((a ptr) (b ptr)) i32 (c-strncmp a b 1)))
      (let ((r (text-of buf ""))) (c-free buf) r))))

(sort-chars "cadb")    ; => "abcd"
```

- لا يمكن تمرير إلا الدوال **التي ليس لها متغيرات حرة**. فالدوال في المستوى الأعلى و`lambda` ودوال
  `labels` المحلية كلها تصلح، لكن الإشارة إلى متغير محلي من نطاق محيط خطأ عند فحص الأنواع. فـ C
  لا تمرّر إلا الوسائط المعلنة، فلا توجد طريقة لتسليم المتغيرات الملتقَطة. وللاحتفاظ بحالة استخدم
  المتغيرات العامة.
- لا يمكن تمرير متغير يحمل دالة. اكتب اسم دالة أو تعبير `lambda` في موضعه مباشرة.
- يصل `panic` أو `throw` داخل دالة الاستدعاء الراجع إلى المستدعي بعد عودة دالة C.
- لا يمكن استدعاء الدالة الراجعة إلا أثناء عمل دالة C التي استدعتها typelisp. ولا يمكن استخدامها من
  أمور مثل `atexit` أو معالجات الإشارات.

## 7. بنى C

لتمرير شيء مثل مصفوفة بنى إلى دالة C أعلن بنية لها التخطيط نفسه كما في C باستخدام `def-c-struct`
واحجزها داخل `unsafe`.

```lisp
(unsafe (def-c-struct item (key i32) (tag u8)))    ; تُعلن داخل unsafe في المستوى الأعلى

(defffi (c-qsort "qsort") (ptr c-ulong c-ulong (fn ((ptr item) (ptr item)) i32)) ())

(defun put ((xs (ptr item)) (i int) (k i32)) i32
  (unsafe (let ((p (c-ref xs i))) (setf p::key k))))

(defun key-at ((xs (ptr item)) (i int)) int
  (unsafe (let ((p (c-ref xs i))) (as int p::key))))

(defun sorted-keys () int
  (unsafe
    (let ((xs (c-alloc item 4)))                    ; أربعة عناصر كلها أصفار
      (put xs 0 3) (put xs 1 1) (put xs 2 4) (put xs 3 2)
      (c-qsort (as ptr xs) 4 8
               (lambda ((a (ptr item)) (b (ptr item))) i32 (- a::key b::key)))
      (+ (* 1000 (key-at xs 0)) (* 100 (key-at xs 1))
         (* 10 (key-at xs 2)) (key-at xs 3)))))

(sorted-keys)    ; => 1234
```

- `(c-alloc T n)` تحجز `n` قيمة من النوع `T` وتعيد `(ptr T)`. و`(c-ref p i)` مؤشر إلى العنصر رقم `i`،
  و`p::field` حقل، و`(c-deref p)` هي ما يشير إليه مؤشر إلى قيمة عددية مثل `i32`. ويمكن كتابتها كلها
  مع `setf`.
- `(as ptr p)` تحوّله إلى `ptr` غير منمّط لتمريره إلى دوال C التي تأخذ `void *`.
- يتحدد حجم `item` (8 هنا) وموضع كل حقل بالقواعد نفسها كما في C.

### عمر الذاكرة المحجوزة

تُحرَّر الذاكرة المحجوزة عندما يغادر التحكم أبعد `unsafe` خارجي في تلك الدالة. ويحدث الشيء نفسه عند
المغادرة بسبب `panic` أو `throw`. ولهذا لا يمكن أخذ قيمة `(ptr T)` إلى خارج `unsafe`. فجعلها قيمة
`unsafe` أو التقاطها في closure أو تمريرها إلى `task` أو رميها بـ `throw` كلها أخطاء أنواع. انسخ
القيم التي تريد استخدامها في الخارج إلى أرقام أو إلى `defstruct` داخل `unsafe`.

وعند الحجز داخل `lambda` أو دالة `labels` اكتب `unsafe` داخل تلك الدالة.

### الذاكرة التي تحجزها C

المؤشر الذي يُستلم من C على أنه `(ptr T)` (قيمة راجعة من `defffi` أو وسيط استدعاء راجع وما إلى ذلك)
يكون خطأ ما لم يشر إلى داخل ذاكرة محجوزة بـ `c-alloc`. أعلن الدوال التي تستلم ذاكرة حجزتها C بـ
`malloc`، أو NULL، بالنوع غير المنمّط `ptr`.

## 8. ما لا يمكن فعله

- **الدوال متغيرة الوسائط** (`printf` ونحوها) لا يمكن إعلانها. فالجزء المتغير يُمرَّر بقواعد مختلفة عن
  الوسائط الثابتة. أعلن اسمًا منفصلًا لكل عدد من الوسائط تستخدمه.
- **تمرير البنى أو إعادتها بالقيمة** غير ممكن. استخدم دوالًا تمرّر مؤشرات.
- **الإعلانات العامة (generic)** غير ممكنة.
- **لا يمكن استخدام اسم دالة مضمنة نفسه.**
- **لا يمكن تمريرها كقيم دوال.** لا يمكنك تمرير إحداها كما في `(map xs c-abs)`؛ غلّفها بـ `lambda`.

  ```lisp
  (unsafe (lambda ((n i32)) i32 (c-abs n)))
  ```
