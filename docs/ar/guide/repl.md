# الـ REPL

عند تشغيل `typl` بلا وسائط تدخل الـ REPL (الوضع التفاعلي). يشرح هذا المستند ما يقدّمه الـ REPL
إلى جانب تقييم التعبيرات: أوامره، والمساعدة أثناء الكتابة، والرجوع إلى النتائج السابقة، وإيقاف
حساب ما، والتحقق بعد حدوث خطأ.

## التشغيل والخروج

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

تخرج بـ `:quit` (اختصارًا `:q`) أو `Ctrl+D`. يُحفظ سجل الإدخال في `~/.typl_history`، فيمكن في
التشغيل التالي استدعاؤه بـ `Ctrl+P` / `Ctrl+N` أو `Ctrl+R` (البحث في السجل).

عند التشغيل، وقبل أول محث، يُنفَّذ ما يلي بالترتيب. ولا يطبع أيٌّ منها القيم التي ينتجها.

1. محتوى `~/.typlrc` إن وُجد. ومع `--no-init` لا يُقرأ.
2. `--eval FORM` و`--load FILE` من سطر الأوامر، بالترتيب الذي كُتبا به. ويمكن تكرار كلٍّ منهما
   أي عدد من المرات.

```
$ typl --load util.typl --eval '(println "ready")'
ready
typl>
```

الخيارات `--eval` و`--load` و`--no-init` خاصة بتشغيل الـ REPL. وإعطاؤها عند تشغيل ملف خطأ.

يبدأ الـ REPL في الوحدة `user`. وعند الانتقال إلى وحدة أخرى بـ `(in-module foo)` يعرض المحث تلك
الوحدة.

```
typl> (in-module foo)
typl user::foo>
```

## أوامر الـ REPL

الاسم `:اسم` المكتوب في أول السطر أمر من أوامر الـ REPL. ويعرض `:help` قائمتها. أما `:اسم` غير
الموجود في القائمة فليس أمرًا، ويُقيَّم كلمةً مفتاحية عادية.

| الأمر | المعنى |
|---|---|
| `:help` (`:h`، `:?`) | عرض قائمة الأوامر |
| `:type FORM` (`:t`) | عرض نوع FORM دون تقييمه |
| `:describe NAME` (`:d`) | عرض نوع التعريف، ونمطه، وحقوله أو متغيّراته، وطرائقه، والسمات (traits) التي ينفّذها، ومكان تعريفه، وسلسلة توثيقه |
| `:apropos TEXT` | البحث في كل الوحدات عن التعريفات التي يحتوي اسمها على TEXT (دون التمييز بين الأحرف الكبيرة والصغيرة) |
| `:src NAME` | عرض مصدر تعريف |
| `:who-calls NAME` | عرض الدوال والطرائق التي تستدعي الدالة أو الطريقة NAME |
| `:inspect FORM` (`:i`) | تقييم FORM وفتح قيمته بحسب نوعها |
| `:backtrace` (`:bt`) | عرض الاستدعاءات التي كانت جارية عند فشل السطر السابق، من الأعمق إلى الخارج |
| `:locals [N]` | عرض وسائط الاستدعاء رقم N في `:backtrace` (رقم 0 عند حذف N) |
| `:cd [DIR]` | نقل المجلد الحالي إلى DIR (إلى المجلد الرئيسي عند حذفه) |
| `:pwd` | عرض المجلد الحالي |
| `:quit` (`:exit`، `:q`) | الخروج من الـ REPL |

يمكن أن يكون NAME اسمًا مثل `inner`، أو مسارًا مثل `std::seq::reverse` أو `Option::unwrap`.

```
typl> (defun inner ((x int) (s string)) int "يضيف 1 إلى x." (+ x 1))
typl> :describe inner
user::inner is a function
  type: (fn (int string) int)
  parameters: x s
  defined at <stdin>:1:1

يضيف 1 إلى x.
typl> :src inner
(defun inner ((x int) (s string)) int "يضيف 1 إلى x." (+ x 1))
```

يعرض `:src` التعريف المحمَّل من ملف من ذلك الملف، والتعريف المكتوب في الـ REPL من النص المكتوب.
ولا يُسجَّل موضع المصدر لتعريفات المكتبة القياسية، فلا يمكن عرض مصدرها.

يبحث `:who-calls` في أجسام دوال الجلسة الحالية. وفي الدالة العامة (generic) لا يجد إلا الاستخدامات
التي جرى تخصيصها بأنواع محددة.

يغيّر `:cd` المجلد الذي يبحث فيه `(load ...)`، لكن `use` يواصل البحث عن الملفات في المجلد الذي
شُغّل فيه الـ REPL.

## فتح قيمة (`:inspect`)

يفتح `:inspect` القيمة بحسب نوعها. فالبنية تُفتح إلى حقولها، والتعداد (ومنه `Option`) إلى حقول
متغيّره، و`Vector` إلى عناصره، و`HashTable` إلى مفاتيحه وقيمه. اكتب رقمًا للدخول إلى ذلك الجزء،
و`u` للرجوع مستوى واحدًا، و`q` للإنهاء.

```
typl> (defstruct point (x int) (y Option<int>))
typl> :inspect (make-instance 'point :x 1 :y (Some 2))
(make-instance 'point :x 1 :y (Some 2)) = #<point x: 1 y: (Some 2)>
  type: point
  0. x = 1
  1. y = (Some 2)
inspect> 1
y = (Some 2)
  type: Option<int>
  0. Some 0 = 2
inspect> q
```

لا تُفتح القوائم ولا `Sexpr`، بل تُعرض كما هي.

## المساعدة أثناء الكتابة

عند الكتابة في طرفية يتوفر ما يلي.

- يُكمل `Tab` الأسماء (التعريفات والصيغ مثل `if` و`defun`)، والمسارات التي فيها `::`، وأوامر الـ REPL
  في أول السطر، وأسماء الملفات داخل سلسلة نصية.
- بعد كتابة اسم دالة متبوعًا بمسافة، يظهر نوع تلك الدالة باهتًا في آخر السطر.
- يُبرَز القوس المقابل للقوس المجاور للمؤشر.
- إذا ضغطت Enter قبل اكتمال الصيغة، يبدأ السطر التالي بإزاحة بقدر عدد الأقواس المفتوحة.

## النتائج السابقة (`:*`، `:**`، `:***`)

في الـ REPL يكون `:*` آخر قيمة عُرضت، و`:**` التي قبلها، و`:***` التي قبل ذلك. ولكلٍّ منها نوع
قيمته.

```
typl> 1
1
typl> "a"
"a"
typl> 2
2
typl> (+ :*** :*)
3
```

- الإدخال الذي لم يعرض قيمة (كالتعريف) أو الذي فشل لا يُزيح النتائج.
- كتابة `:**` أو `:***` قبل أن يتوفر هذا العدد من النتائج خطأ.
- `':*` المقتبس كلمة مفتاحية عادية.
- يبقى `:*` المكتوب في جسم دالة مشيرًا إلى النتيجة وقت تعريف الدالة. فـ `*` في Common Lisp يقرأ
  القيمة وقت الاستدعاء، أما typelisp فيثبّتها وقت التعريف ليكون لها نوع.
- خارج الـ REPL (عند تشغيل ملف، وفي `~/.typlrc` و`--load` و`--eval`) يكون `:*` كلمة مفتاحية عادية.

## إيقاف حساب (`Ctrl+C`)

الضغط على `Ctrl+C` أثناء التقييم يوقف ذلك الحساب ويعود إلى المحث. ويبقى ما عرّفته من قبل. ويعمل
ذلك سواء أكان الحساب حلقةً في المفسّر، أم حلقةً في شيفرة مترجمة، أم انتظارًا في `sleep` أو `wait`.
وتُنفَّذ أعمال التنظيف في `unwind-protect` الجارية.

```
typl> (loop)
^Cerror: interrupted
typl>
```

`Ctrl+C` أثناء الكتابة يتجاهل السطر الجاري كتابته فقط.

## التحقق بعد الخطأ (`:backtrace`، `:locals`)

بعد أن يتوقف التقييم بخطأ، يعرض `:backtrace` (`:bt`) استدعاءات الدوال التي كانت جارية حينها، من
الأعمق إلى الخارج. ويعرض `:locals N` وسائط الاستدعاء رقم N بحسب أنواعها المعلنة.

```
typl> (defun inner ((x int)) int (if (= x 0) (panic "boom") x))
typl> (defun outer ((n int)) int (* 2 (inner n)))
typl> (outer 0)
error: <stdin>:1:40: panic: boom
typl> :bt
  0: (user::inner 0)  called at <stdin>:1:33
  1: (user::outer 0)  called at <stdin>:1:1
typl> :locals 1
  n = 0
```

- في الاستدعاء من آخر تعبير في الدالة (الاستدعاء الذيلي) لا تُعرض الدالة المستدعية. وبفضل ذلك
  لا تشغل حلقة الاستدعاء الذاتي الذيلي إلا مساحة استدعاء واحد مهما دارت.
- لا تُعرض الاستدعاءات داخل الدوال المترجمة ولا الدوال المجهولة (`lambda`).
- يعرض `:locals` الوسائط فقط، لا المتغيرات المربوطة بـ `let`.
- عند تقييم السطر التالي يُحذف سجل الخطأ السابق.
