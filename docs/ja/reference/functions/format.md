# 書式ディレクティブ

`print`/`println`/`format` の制御文字列に書くディレクティブ。CL の `format` ディレクティブを
ほぼ網羅する。関数そのものの説明は [印字](printing.md#1-print--println--format)。

## 1. 書き方

各ディレクティブは `~`、任意の**プレフィックスパラメータ**（カンマ区切り。整数 / `'c`（文字）/
`v`（次の引数から取る）/ `#`（残り引数の数））、任意の**修飾子** `:`・`@`、ディレクティブ文字、の順。
ディレクティブ文字は大文字小文字を区別しない。

制御文字列はリテラルでなければならない（[印字](printing.md#1-print--println--format)）。その上で
チェック時に次を検査する。

- **引数の数と型**。引数を消費するディレクティブごとに、引数が残っているか、受け付ける型か
  （下の表の「引数」列）。`~*` による移動、`~[` のどの節、`~^` が効くかどうか、`~@{` の反復回数の
  ように実行時の値で道が分かれるところは、**すべての道**を検査する。引数が余るのは構わない（CL と同じ）。
- **パラメータと修飾子**。受け付けない修飾子、数の多すぎるパラメータ、範囲外の値
  （負の幅、2〜36 以外の基数、文字を取る位置の整数など）はエラー。黙って無視したり丸めたりはしない。

リスト引数（`~{`・`~:{`・`~<...~:>`）の**要素**は `Sexpr` で、個数も各要素の型も型からは分からない。
要素に対する要求（`~c` なら文字、など）と要素の不足は、値が届いたときに検査して実行時エラーになる
（別の表示に切り替えることはない）。

`~d` `~b` `~o` `~x` と基数付きの `~r` は CL と同じく、整数でない値を `~a` と同じく十進で表示する
（`(format false "~5d" 1/2)` は `"  1/2"`）。それ以外の CL の寛容な規則は採らない。`~:[` が任意の値を
真偽として扱う、といった読み替えはせず、型エラーにする。

## 2. 出力（引数を1つ消費する）

| ディレクティブ | パラメータ / 修飾子 | 意味 |
|---|---|---|
| `~a` | `~mincol,colinc,minpad,padchar` / `@`=右詰め | aesthetic（CL `princ`。文字列クォートなし）。引数は任意の型 |
| `~s` | 同上 | standard（CL `prin1`。読み戻せる表現）。引数は任意の型 |
| `~w` | — | CL の `write`。`*print-pretty*` が真なら整形出力、偽なら `~s` と同義 |
| `~d` `~b` `~o` `~x` | `~mincol,padchar,commachar,interval` / `:`=桁区切り, `@`=符号必須 | 10/2/8/16進整数。引数は任意（整数でなければ `~a` と同じく十進で表示） |
| `~r` | `~radix,mincol,padchar,commachar,interval`（基数指定）または無指定 | 基数指定時はその進数（基数は 2〜36）。無指定で `~r`=英語基数、`~:r`=英語序数、`~@r`=ローマ数字、`~:@r`=旧ローマ数字。引数は整数 |
| `~p` | `:`=1つ戻る, `@`=y/ies | 複数形（`~p`→"s"、`~@p`→"y"/"ies"）。引数は整数 |
| `~c` | `:`=名前, `@`=`#\`構文 | 文字。引数は `char` |
| `~f` | `~w,d,k,overflowchar,padchar` / `@`=符号 | 固定小数点。引数は数 |
| `~e` | `~w,d,,,,padchar,exptchar` / `@`=符号 | 指数表記。引数は数。CL の exponent-digits・scale・overflowchar パラメータには対応しない（指定するとエラー） |
| `~g` | `@`=符号 | 汎用浮動小数点。引数は数。パラメータは取らない |
| `~$` | `~d,n,w,padchar` / `:`,`@` | 金額表記。引数は数 |

## 3. 出力（引数を消費しない）

| ディレクティブ | 意味 |
|---|---|
| `~%` | 改行（`~n%` で n 個） |
| `~&` | fresh-line（行頭でなければ改行。`~n&`） |
| `~\|` | 改ページ（form feed） |
| `~~` | リテラルの `~`（`~n~` で n 個） |
| `~t` | タブ（`~colnum,colincT`。すでに colnum 以上の桁にいれば colinc の倍数だけ進む。colinc が 0 なら進まない。`@`=相対。`:`=論理ブロック起点のタブで、pretty 時だけ働く） |
| `~_` | 条件改行（pretty。素=`:linear` / `~:_`=`:fill` / `~@_`=`:miser` / `~:@_`=`:mandatory`） |
| `~i` | インデント（pretty。`~ni`=ブロック起点+n / `~n:i`=現在桁+n） |
| `~<改行>` | 改行を無視（`:`=空白保持, `@`=改行保持） |

pretty printer 系のディレクティブ（`~_` `~i` `~:t` `~<...~:>`、および `~a`/`~s`/`~w` の整形経路）は、
`*print-pretty*` が偽のとき CL 同様すべて何もしない。既定は偽。

## 4. 制御構造

| ディレクティブ | 意味 |
|---|---|
| `~(...~)` | 大文字小文字変換（`~(`小文字, `~:(`各語頭大文字, `~@(`先頭のみ大文字, `~:@(`全大文字） |
| `~[...~;...~]` | 条件選択（整数の引数で分岐。`~n[`・`~v[`・`~#[` ならその値で分岐して引数は取らない。`~:;`=デフォルト節で最後の節に限る）。`~:[偽~;真~]` は `bool` の引数で分岐し、節はちょうど2つ |
| `~{...~}` | 反復（リスト引数を走査。`~:{`=部分リストごと, `~@{`=残り引数, `~:@{`=残り引数の各リストごと, `~^`=脱出, `~:}`=空でも1回）。1回の反復で引数を1つも消費しない本体はエラー（終わらないため） |
| `~<...~;...~>` | 桁揃え（セグメントを `~mincol` 幅に分散。`:`/`@`=端の詰め） |
| `~<...~;...~:>` | **論理ブロック**（閉じが `~:>`。上の桁揃えとは別物）。先頭セグメント=prefix、末尾=suffix（いずれもリテラル文字列のみ）。`~@;` 区切りなら prefix は**行頭 prefix**。`~:<` は prefix/suffix を `(`/`)` に既定。引数はリスト1つ（`~@<` は残り引数をその場で使う） |
| `~*` | 引数スキップ（`~n*`=n個進む, `~:*`=戻る, `~@*`=絶対位置へ） |
| `~/name/` | 関数・メソッドの呼び出し（5 章。`:`/`@` フラグが呼ぶ先へ渡る。パラメータは取らない） |

CL の次のディレクティブには対応しない（チェック時のエラー）。

- `~?`・`~@?`：制御文字列を実行時の引数として受け取るので、中のディレクティブが消費する引数を
  検査できない。そのディレクティブを制御文字列へ直接書く。
- `~@[...~]`：引数が nil でないかを調べるが、この言語には nil が無い。`bool` で分岐する
  `~:[偽~;真~]` を使う。
- 本体が空の `~{~}`：本体を実行時の引数から取る。ディレクティブを括弧の中に書く。

## 5. `~/name/`

`~/name/` は、その場所で `(name 引数 colon at)` と書いた呼び出しと同じ規則で `name` を解決し、
呼んだ結果の文字列を出力する。引数を 1 つ消費する。`colon`・`at` はディレクティブに `:`・`@` が
付いているかを表す `bool`。

```lisp
(defstruct point (x i32) (y i32))
(impl point
  (brief (self (colon bool) (at bool)) string
    (if colon (format false "<~a,~a>" self::x self::y) (format false "~a/~a" self::x self::y))))
(defun yen ((n int) (colon bool) (at bool)) string
  (format false "~a yen" n))

(println "~a" (format false "~/brief/"  (make-instance 'point :x 3 :y 4)))   ; => 3/4
(println "~a" (format false "~:/brief/" (make-instance 'point :x 3 :y 4)))   ; => <3,4>
(println "~a" (format false "~/yen/" 500))                                    ; => 500 yen
```

- 名前の解決は普通の呼び出しと同じ（[構文リファレンス 3.10](../syntax.md#310-module--use--名前空間)）。
  引数の型にメソッド `name` があればそれ、無ければ見えている関数 `name` を呼ぶ。モジュールの
  関数はパスで書ける（`~/m::shout/`）。
- 呼べるのは、typelisp で書いた関数かメソッドで、引数・`colon`・`at` をそのまま受け取り
  `string` を返すもの。組み込みの関数は呼べない。
- **呼ぶ先はチェック時に決まる**。チェッカーは `~*` や `~[` による移動も考えて、その `~/name/` に
  当たりうる引数をすべて求め、それぞれの型で解決する。どれかで解決できなければチェック時の
  エラーになり、当たりうる引数によって呼ぶ先が 2 つに分かれる場合もエラーになる。実行時に名前を
  探すことはないので、AOT 実行ファイルでも同じように動く。
- **`~{`・`~:{`・`~:@{`・`~<...~:>` の中では使えない**（チェック時のエラー）。リスト引数の要素の
  型は `Sexpr` で、呼ぶ先を決める型にならないため。`~@{` は呼び出しの残りの引数を回すので、
  型が分かり、使える。

CL との違い: CL は名前をグローバル関数として引く。ここでは呼び出しと同じ解決なので、引数の型の
メソッドが同じ名前の関数より先に選ばれる。
