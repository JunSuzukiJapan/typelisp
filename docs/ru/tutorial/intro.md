# Первые шаги

Начиная с вычисления выражений в REPL, эта глава по порядку рассматривает функции, переменные, ветвления, циклы, а
также списки и `Vector`. О сборке `typl` см. [README.md](../../../README.md).

## 1. Запуск REPL

Запущенный без аргументов, `typl` входит в REPL (интерактивный режим). Введите выражение после `typl>` — оно сразу
вычисляется, и выводится его значение. `:quit` выходит из REPL.

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

Далее ввод в REPL и результаты показываются в таком виде.

## 2. Вычисление выражений

typelisp — это Лисп, поэтому выражение заключается в скобки, и **оператор или имя функции идёт первым**. Пишут
`(+ 1 2)`, а не `1 + 2`.

```
typl> (* 2 (+ 3 4))
14
typl> (+ 1 2 3 4)
10
typl> "hello"
"hello"
typl> (upcase "hello")
"HELLO"
```

Числа бывают таких видов:

- **Целые** имеют тип `int`. Верхнего предела у их размера нет.
- **Дробные** имеют тип `f64`. Их пишут с десятичной точкой, например `1.5` или `2.0`.
- Смешивать `int` и `f64` в вычислении нельзя. `(+ 1 2.0)` — ошибка типа. Для преобразования пишите `(as f64 1)`.

```
typl> (* 123456789012345 123456789012345)
15241578753238669120562399025
typl> (/ 7 2)
3
typl> (/ 7.0 2.0)
3.5
```

`/` над двумя целыми даёт целое с отброшенной дробной частью (дробь, как в Common Lisp, не получается). Для остатка
используйте `(mod 7 2)`.

Логические значения — `true` и `false`.

```
typl> (> 3 2)
true
typl> (and (> 3 2) (< 3 2))
false
```

## 3. Определение функций

Функции определяются с помощью `defun`. **Типы аргументов и тип результата пишутся всегда.**

```lisp
(defun square ((n int)) int
  (* n n))
```

- `(n int)` означает «аргумент `n` типа `int`». Несколько аргументов перечисляются: `((a int) (b int))`.
- `int` после списка аргументов — тип результата.
- Значение последнего выражения в теле — это результат функции. `return` не пишут.

```
typl> (defun square ((n int)) int (* n n))
typl> (square 12)
144
typl> (square "a")
error: <stdin>:1:9: type error: type mismatch: expected `int`, found `string`
```

Вызов с несовпадающими типами сообщается как ошибка типа **до выполнения**. При запуске файла одна-единственная
ошибка типа где угодно означает, что не выполнится ни одна строка программы.

Чтобы сделать аргумент необязательным, используйте `&optional`. Если задать значение по умолчанию, аргумент
принимает его, когда опущен.

```lisp
(defun greet ((name string) &optional (greeting string "Hello")) string
  (format false "~a, ~a!" greeting name))
```

```
typl> (greet "Ann")
"Hello, Ann!"
typl> (greet "Ann" "Hi")
"Hi, Ann!"
```

`false` в первом аргументе `format` означает «вернуть результат строкой, а не выводить его». Каждое `~a` заменяется
следующим аргументом.

## 4. Переменные

Локальные переменные создаются с помощью `let`.

```lisp
(defun sum-of-squares ((a int) (b int)) int
  (let ((aa (square a))
        (bb (square b)))
    (+ aa bb)))
```

- Тип переменной `let` берётся из её начального значения. Писать его не нужно.
- Переменные одного `let` не могут ссылаться друг на друга. Чтобы построить переменную из предыдущей, используйте
  `let*`.

```
typl> (let* ((a 1) (b (+ a 1))) (* a b))
2
```

Чтобы изменить значение переменной, используйте `setf`. **Присваивание не может изменить тип переменной.**

```
typl> (let ((x 1)) (setf x "a"))
error: <stdin>:1:22: type error: type mismatch: expected `int`, found `string`
```

Глобальные переменные определяются с помощью `defvar`. Здесь тип указывается.

```lisp
(defvar (counter int) 0)
```

## 5. Ветвления

### if

Пишите `(if условие выражение-то выражение-иначе)`. **Ветвь «иначе» опустить нельзя.**

```lisp
(defun sign ((n int)) string
  (if (< n 0) "negative" "non-negative"))
```

- Условием может быть только выражение типа `bool`. Запись числа, как `(if 0 ...)`, — ошибка типа.
- Выражения «то» и «иначе» должны иметь один тип.

Когда в ложном случае ничего не должно происходить, используйте `when` (и `unless` для обратного).

```lisp
(defun report-size ((n int)) ()
  (when (> n 100)
    (println "large")
    (println "really large")))
```

### cond

При трёх и более условиях `cond` читается лучше. Завершающий `else` выбирается, когда ни одно из условий не
выполнено.

```lisp
(defun describe-number ((n int)) string
  (cond ((< n 0) "negative")
        ((= n 0) "zero")
        ((< n 10) "small")
        (else "large")))
```

### match

Чтобы ветвиться по форме значения, используйте `match`.

```lisp
(defun day-name ((d int)) string
  (match d
    (0 "Sun")
    (6 "Sat")
    (_ "weekday")))
```

`_` совпадает с любым значением. У `int` бесчисленное множество значений, поэтому без ветви `_` будет ошибка о
том, что покрыты не все случаи. По-настоящему `match` раскрывается при разборе `Option` и собственных типов, о
которых рассказывает следующая глава, [Основы типов](types.md).

## 6. Циклы

Функция может вызывать саму себя.

```lisp
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))
```

```
typl> (fact 30)
265252859812191058636308480000000
```

Для фиксированного числа повторений используйте `dotimes`. `i` пробегает от 0 до `n - 1`.

```lisp
(defun sum-to ((n int)) int
  (let ((total 0))
    (dotimes (i (+ n 1))
      (setf total (+ total i)))
    total))
```

```
typl> (sum-to 100)
5050
```

Есть также `while`, `do` и расширенный `loop` из Common Lisp. Слова-предложения расширенного `loop` пишутся как
ключевые слова (`:for`, `:collect` и т. д.).

```
typl> (loop :for i :from 1 :to 5 :collect (* i i))
#(1 4 9 16 25)
```

## 7. Списки и Vector

### Vector

Чтобы хранить последовательность значений одного типа, используйте `Vector<T>`. `T` — тип элементов.

```lisp
(let ((v (the Vector<int> (Vector::new))))
  (push v 3)
  (push v 1)
  (push v 2)
  (println "~a" v))
;; выводит #(3 1 2)
```

- Один лишь `(Vector::new)` не определяет тип элементов, поэтому задайте тип через `(the Vector<int> ...)`.
- `(push v x)` добавляет в конец, `(get v i)` читает элемент `i`, а `(len v)` даёт длину.
- `get` с индексом вне диапазона останавливает программу с ошибкой.

### lambda и функции высшего порядка

Анонимные функции создаются с помощью `lambda`. Как и в `defun`, указываются типы аргументов и результата.

```
typl> ((lambda ((x int)) int (* x 2)) 21)
42
```

`map`, `filter`, `sort`, `foldl` и подобные принимают `Vector`, превращённый в **итератор**
через `(iter v)`. Коллекция идёт первой, функция — второй. `v` выше связана через `let`,
поэтому за пределами этого `let` её использовать нельзя. В следующем примере `v` сначала
определяется через `defvar`.

```lisp
(defvar (v Vector<int>) (Vector::new))
(push v 3)
(push v 1)
(push v 2)

(map (iter v) (lambda ((x int)) int (* x 10)))                 ; => #(30 10 20)
(filter (iter v) (lambda ((x int)) bool (> x 1)))              ; => #(3 2)
(sort (iter v) (lambda ((a int) (b int)) bool (< a b)))        ; => #(1 2 3)
(foldl (iter v) (lambda ((acc int) (x int)) int (+ acc x)) 0)  ; => 6
```

Чтобы обработать элементы по одному, используйте `doiter`.

```lisp
(doiter (x (iter v))
  (println "item ~a" x))
```

Функция, принимающая функцию в качестве аргумента, записывает тип этого аргумента как
`(fn (типы-аргументов...) тип-результата)`. Функцию, определённую через `defun`, можно передать как значение по
имени.

```lisp
(defun twice ((f (fn (int) int)) (x int)) int
  (f (f x)))

(twice square 3)                                ; => 81
(twice (lambda ((x int)) int (* x 3)) 2)        ; => 18
```

### Списки (S-выражения)

Списки, созданные через `'(1 2 3)` или `(list 1 2 3)`, — это **данные S-выражений**. Их элементы не обязаны иметь
один тип.

```
typl> '(1 2 3)
(1 2 3)
typl> (list 1 "two" 'three)
(1 "two" three)
```

Данные S-выражений нужны главным образом для работы с самими программами — в макросах ([Макросы](macros.md)) и с
`read`. Для данных с известным типом элементов используйте `Vector<T>`. Список S-выражений можно обойти через
`dolist`.

```lisp
(dolist (x '(1 2 3))
  (println "x=~a" x))
```

Пара из двух значений создаётся через `cons` и разбирается через `car` и `cdr`.

```
typl> (let ((p (cons "age" 42))) (cdr p))
42
```

## 8. Программа в файле

Программу можно записать в файл (с расширением `.typl`) и запустить командой `typl имя-файла`. Для вывода
результатов используйте `println`.

```lisp
;; hello.typl
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))

(dotimes (i 5)
  (println "~a! = ~a" i (fact i)))
```

```sh
$ typl hello.typl
0! = 1
1! = 1
2! = 2
3! = 6
4! = 24
```

- `println` выводит с теми же директивами, что и `format`, и завершает строку переводом строки. `print` перевода
  строки не добавляет.
- `~a` вставляет значение в виде, удобном человеку, а `~s` — в виде, который можно прочитать обратно (строки
  сохраняют свои `"`).
- Файл читается сверху вниз. **Функцию нельзя вызвать до её определения.**
