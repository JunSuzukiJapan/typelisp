# Макросы

Макрос — это функция, которая принимает программу и возвращает программу. Макросы позволяют создавать новый
синтаксис, который не выразить функциями. Макросы typelisp работают так же, как `defmacro` в Common Lisp.
Предполагается, что вы прочитали раздел «Списки (S-выражения)» в [Первых шагах](intro.md).

## 1. Чем макросы отличаются от функций

Функция получает аргументы **после их вычисления**. Макрос получает их **в виде выражений, до вычисления** (как
данные S-выражений), строит другое выражение и возвращает его. Возвращённое выражение заменяет вызов макроса, и
только тогда оно проверяется и выполняется. Такая замена называется **раскрытием**.

Например, синтаксис вроде `unless` нельзя написать функцией. Будь это функцией, тело вычислялось бы первым, даже
когда условие истинно.

## 2. `defmacro` и квазицитирование

Создадим `my-unless`, который выполняет тело, только когда условие ложно.

```lisp
(defmacro my-unless (test &rest body)
  `(if ,test () (progn ,@body ())))
```

- Для аргументов макроса типы не пишутся. Каждый аргумент — данные S-выражения.
- `&rest body` получает оставшиеся аргументы, собранные в один список.
- Выражение, начинающееся с `` ` `` (квазицитирование), строится как данные, в том виде, как написано. Внутри него:
  - `,test` вставляет содержимое переменной `test` в это место.
  - `,@body` вклеивает в это место элементы списка `body`.

```lisp
(my-unless (> 1 2)
  (println "one")
  (println "two"))
;; one
;; two
```

Раскрытие можно проверить с помощью `macroexpand-1`. При написании макроса самый быстрый путь — сначала посмотреть
на его раскрытие.

```
typl> (macroexpand-1 '(my-unless (> 1 2) (println "one")))
(ok (if (> 1 2) () (progn (println "one") ())))
```

## 3. Раскрытия тоже проверяются по типам

Выражение, которое возвращает макрос, проверяется по типам так же, как любое выражение, написанное вручную.

```
typl> (defmacro add-a (x) `(+ ,x "a"))
typl> (add-a 1)
error: <stdin>:1:1: type error: type mismatch: expected `int`, found `string`
```

Об ошибке сообщается в месте вызова макроса.

Правила, что ветвь «иначе» у `if` нельзя опустить и что обе ветви `if` должны иметь один тип, применяются к
раскрытиям как есть. `my-unless` выше заканчивается на `(progn ,@body ())`, чтобы при любом типе последнего
выражения тела обе ветви `if` имели тип `()`.

## 4. Конфликты имён и `gensym`

Прямолинейный макрос, обменивающий значения двух переменных, выглядит так:

```lisp
(defmacro swap-bad (a b)
  `(let ((tmp ,a))
     (setf ,a ,b)
     (setf ,b tmp)))
```

Обычно он работает, но ломается, когда переменная вызывающего называется именно `tmp`.

```lisp
(let ((tmp 1) (other 2))
  (swap-bad tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=1 other=2   (не обменялись)
```

Раскрытие — `(let ((tmp tmp)) (setf tmp other) (setf other tmp))`, и `tmp`, созданный макросом, скрывает `tmp`
вызывающего.

Чтобы этого избежать, создавайте имена переменных, используемых внутри макроса, с помощью `gensym`. `gensym`
возвращает новый символ, который невозможно написать нигде в программе.

```lisp
(defmacro swap (a b)
  (let ((tmp (gensym "tmp")))
    `(let ((,tmp ,a))
       (setf ,a ,b)
       (setf ,b ,tmp))))
```

```lisp
(let ((tmp 1) (other 2))
  (swap tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=2 other=1
```

Как и в Common Lisp, макросы typelisp не предотвращают конфликты имён автоматически (они негигиеничны). Запомните:
**используйте `gensym` для привязок, которые создаёт макрос.**

Точно так же макрос, повторяющий тело заданное число раз, можно написать так:

```lisp
(defmacro repeat (n &rest body)
  (let ((i (gensym "i")))
    `(dotimes (,i ,n) ,@body)))

(repeat 3 (println "hi"))
```

## 5. Раскрытие, зависящее от аргументов

Тело макроса — обычный код typelisp, поэтому оно может исследовать аргументы с помощью `if` или `match` и строить
разные раскрытия. Аргументы — данные S-выражений (`Option<Sexpr>`), а пустой список — это `none`.

Создадим `my-and`, который возвращает `true`, если все его условия истинны.

```lisp
(defmacro my-and (&rest forms)
  (match forms
    ((none) 'true)                                    ; нет аргументов
    ((cons f more)
     (if (sexpr-null more)
         f                                            ; ровно один
         `(if ,f (my-and ,@more) false)))             ; два и больше
    (_ (panic "my-and: not a list"))))

(my-and (> 2 1) (> 3 2))      ; => true
(my-and (> 2 1) (> 1 3))      ; => false
```

- `(cons f more)` — образец, который помещает голову списка в `f`, а остаток в `more`.
- `sexpr-null` проверяет, является ли данное S-выражения пустым списком.
- Последняя ветвь `_` нужна, потому что у данных S-выражений есть формы помимо списков (числа, строки и т. д.), и
  `match` требует покрыть и их. Аргумент `&rest` всегда список, так что эта ветвь на деле никогда не выполняется.
- Макрос может вызывать сам себя в своём раскрытии. Раскрытие повторяется, пока не останется вызовов макросов.

## 6. Необязательные аргументы

`&optional` принимает аргументы, которые можно опустить. Можно задать значения по умолчанию.

```lisp
(defmacro inc-by (place &optional (n 1))
  `(setf ,place (+ ,place ,n)))

(let ((c 10))
  (inc-by c)
  (inc-by c 5)
  c)                            ; => 16
```

`&key` принимает ключевые аргументы
([Справочник по синтаксису 3.14](../reference/syntax.md#314-defmacro--определения-макросов)).

## 7. `macrolet`: макросы для одного места

Макрос, используемый только внутри одного выражения, можно определить с помощью `macrolet`. Снаружи он не виден.

```lisp
(macrolet ((sq (x) `(* ,x ,x)))
  (+ (sq 3) (sq 4)))            ; => 25
```

## 8. Что нужно помнить

- **Макрос можно вызывать только после его определения.** Как и функции, определяйте его ближе к началу файла.
- Сделайте макрос доступным другим модулям с помощью `(pub defmacro ...)`.
- Большая часть стандартного синтаксиса, включая `when`, `unless`, `cond`, `and`, `or` и `dotimes`, определена
  макросами. Что внутри, можно посмотреть через `(macroexpand '(when true 1))`.
- Если что-то можно написать функцией, пишите функцией. Макросы нельзя передавать как значения, а чтобы понять, что
  они делают, приходится читать их раскрытие.
