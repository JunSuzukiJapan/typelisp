# 格式指令

寫在 `print`/`println`/`format` 的控制字串中的指令。幾乎涵蓋了 CL 的全部 `format` 指令。函式本身的說明見
[列印](printing.md#1-print--println--format)。

## 1. 寫法

每個指令依序由 `~`、可選的**前綴參數**（以逗號分隔。整數 / `'c`（字元）/ `v`（從下一個引數取）/ `#`（剩餘引數的個數））、可選的**修飾符**
`:`・`@`、指令字元組成。指令字元不區分大小寫。

控制字串必須是字面值（[列印](printing.md#1-print--println--format)）。在此基礎上，檢查時會檢查以下內容。

- **引數的個數與型別。** 對每個消耗引數的指令，檢查是否還有引數、型別是否被接受（下表的「引數」說明）。在由執行期的值決定路徑的地方——
  `~*` 的移動、`~[` 的哪個子句、`~^` 是否生效、`~@{` 的重複次數——會檢查**所有路徑**。引數多出來沒有關係（與 CL 相同）。
- **參數與修飾符。** 不接受的修飾符、過多的參數、超出範圍的值（負的寬度、2〜36 以外的基數、在取字元的位置寫整數等）都是錯誤。不會默默忽略或
  捨入。

串列引數（`~{`・`~:{`・`~<...~:>`）的**元素**是 `Sexpr`，個數與每個元素的型別都無法從型別得知。對元素的要求（`~d` 需要整數等）與元素不足，
在值抵達時檢查，是執行期錯誤（不會切換到別的顯示方式）。

不採用 CL 的寬鬆規則。對 `~d` 傳入非整數時以 `~a` 顯示、`~:[` 把任意值當作真假處理之類的改讀都不做，而是型別錯誤。

## 2. 輸出（消耗一個引數）

| 指令 | 參數 / 修飾符 | 意義 |
|---|---|---|
| `~a` | `~mincol,colinc,minpad,padchar` / `@`=靠右 | aesthetic（CL 的 `princ`。字串不帶引號）。引數可以是任何型別 |
| `~s` | 同上 | standard（CL 的 `prin1`。可讀回的表示）。引數可以是任何型別 |
| `~w` | — | CL 的 `write`。`*print-pretty*` 為真時美化輸出，為假時與 `~s` 相同 |
| `~d` `~b` `~o` `~x` | `~mincol,padchar,commachar,interval` / `:`=分組, `@`=一律帶正負號 | 十／二／八／十六進位整數。引數是整數 |
| `~r` | `~radix,mincol,padchar,commachar,interval`（指定基數）或不指定 | 指定基數時為該進位（基數 2〜36）。不指定時 `~r`=英文基數詞、`~:r`=英文序數詞、`~@r`=羅馬數字、`~:@r`=舊式羅馬數字。引數是整數 |
| `~p` | `:`=回退一個, `@`=y/ies | 複數形（`~p`→"s"、`~@p`→"y"/"ies"）。引數是整數 |
| `~c` | `:`=名稱, `@`=`#\` 語法 | 字元。引數是 `char` |
| `~f` | `~w,d,k,overflowchar,padchar` / `@`=正負號 | 定點數。引數是數 |
| `~e` | `~w,d,,,,padchar,exptchar` / `@`=正負號 | 指數記法。引數是數。不支援 CL 的 exponent-digits、scale、overflowchar 參數（指定時是錯誤） |
| `~g` | `@`=正負號 | 通用浮點。引數是數。不接受參數 |
| `~$` | `~d,n,w,padchar` / `:`,`@` | 金額記法。引數是數 |

## 3. 輸出（不消耗引數）

| 指令 | 意義 |
|---|---|
| `~%` | 換行（`~n%` 為 n 個） |
| `~&` | fresh-line（不在行首時換行。`~n&`） |
| `~\|` | 換頁（form feed） |
| `~~` | 字面的 `~`（`~n~` 為 n 個） |
| `~t` | 定位（`~colnum,colincT`。已在 colnum 欄以後時前進 colinc 的倍數。colinc 為 0 時不前進。`@`=相對。`:`=以邏輯區塊起點為基準的定位，只在 pretty 時作用） |
| `~_` | 條件換行（pretty。無修飾=`:linear` / `~:_`=`:fill` / `~@_`=`:miser` / `~:@_`=`:mandatory`） |
| `~i` | 縮排（pretty。`~ni`=區塊起點+n / `~n:i`=目前欄+n） |
| `~<換行>` | 忽略換行（`:`=保留空白, `@`=保留換行） |

與 CL 一樣，pretty printer 類的指令（`~_` `~i` `~:t` `~<...~:>`，以及 `~a`/`~s`/`~w` 的美化路徑）在 `*print-pretty*` 為假時全部不作用。預設為假。

## 4. 控制結構

| 指令 | 意義 |
|---|---|
| `~(...~)` | 大小寫轉換（`~(` 小寫, `~:(` 每個詞的第一個字母大寫, `~@(` 只有第一個字母大寫, `~:@(` 全部大寫） |
| `~[...~;...~]` | 條件選擇（依整數引數分支。`~n[`・`~v[`・`~#[` 依該值分支，不取引數。`~:;`=預設子句，只能是最後一個子句）。`~:[假~;真~]` 依 `bool` 引數分支，子句恰好 2 個 |
| `~{...~}` | 迭代（走訪串列引數。`~:{`=每個子串列, `~@{`=剩餘引數, `~:@{`=剩餘引數中的每個串列, `~^`=跳出, `~:}`=即使為空也執行 1 次）。一次迭代中一個引數都不消耗的本體是錯誤（不會結束） |
| `~<...~;...~>` | 對齊（把各段分布到 `~mincol` 寬度。`:`/`@`=兩端的填充） |
| `~<...~;...~:>` | **邏輯區塊**（以 `~:>` 結束。與上面的對齊是不同的東西）。第一段=prefix，最後一段=suffix（都只能是字面字串）。以 `~@;` 分隔時 prefix 是**行首 prefix**。`~:<` 把 prefix/suffix 預設為 `(`/`)`。引數是一個串列（`~@<` 就地使用剩餘引數） |
| `~*` | 略過引數（`~n*`=前進 n 個, `~:*`=回退, `~@*`=跳到絕對位置） |
| `~/name/` | 方法呼叫（第 5 章。`:`/`@` 旗標傳給方法。不接受參數） |

不支援 CL 的以下指令（檢查時的錯誤）。

- `~?`・`~@?`：把控制字串當作執行期的引數接收，無法檢查其中指令消耗的引數。請把這些指令直接寫進控制字串。
- `~@[...~]`：檢查引數是否不為 nil，但這個語言沒有 nil。請使用依 `bool` 分支的 `~:[假~;真~]`。
- 本體為空的 `~{~}`：從執行期的引數取本體。請把指令寫在括號裡面。

## 5. `~/name/`

**與 CL 有一點不同：名稱不是以全域函式查找，而是以引數本身型別的方法查找。** 方法的形式為 `((self Self) (colon bool) (at bool)) → string`，
指令的 `:`/`@` 原樣傳入。

CL 那種以全域函式查找的方式在這個語言中無法安全實作。即使控制字串是字面值，串列引數的元素（`~{` 內部）是什麼型別在檢查時也無法決定，只依
名稱查找就可能呼叫到給別的型別準備的函式。依值的型別選擇，該方法正是針對該型別經過型別檢查的，所以是安全的（與 `print-object` 是同一機制）。
它也可以用於 `string`/`bool`/`char`/`symbol`/串列之類的值。只有整數無法從值區分寬度，所以**只在多個整數型別定義了同名方法時**才是錯誤。

無法決定作用於哪個引數，但可以決定可能呼叫哪些方法。檢查器從字面的控制字串收集所有 `~/name/`，記錄該呼叫處的引數型別中具有上述形式方法的
那些。因此，**如果沒有任何引數的型別具有該方法，就是檢查時的錯誤**（而不是執行期），在 AOT 執行檔中也能運作。

```lisp
(defstruct point (x i32) (y i32))
(defmethod brief ((self point) (colon bool) (at bool)) string
  (if colon (format false "<~a,~a>" self::x self::y) (format false "~a/~a" self::x self::y)))
(println "~a" (format false "~/brief/"  (point::new 3 4)))   ; => 3/4
(println "~a" (format false "~:/brief/" (point::new 3 4)))   ; => <3,4>
```
