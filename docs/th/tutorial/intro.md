# เริ่มต้นใช้งาน

บทนี้เริ่มจากการประเมินค่านิพจน์ใน REPL แล้วครอบคลุมฟังก์ชัน ตัวแปร เงื่อนไข ลูป
และลิสต์กับ `Vector` ตามลำดับ วิธีบิลด์ `typl` ดูที่
[README.md](../../../README.md)

## 1. การเริ่ม REPL

เมื่อเริ่ม `typl` โดยไม่มีอาร์กิวเมนต์ จะเข้าสู่ REPL (โหมดโต้ตอบ) พิมพ์นิพจน์หลัง
`typl>` แล้วนิพจน์จะถูกประเมินค่าทันทีและพิมพ์ค่าออกมา `:quit` ออกจาก REPL

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

จากนี้ไป อินพุตและผลลัพธ์ของ REPL จะแสดงในรูปแบบนี้

## 2. การประเมินค่านิพจน์

typelisp เป็น Lisp ดังนั้นนิพจน์จึงถูกห่อด้วยวงเล็บโดยมี **ตัวดำเนินการหรือชื่อฟังก์ชัน
อยู่หน้าสุด** คุณเขียน `(+ 1 2)` ไม่ใช่ `1 + 2`

```
typl> (* 2 (+ 3 4))
14
typl> (+ 1 2 3 4)
10
typl> "hello"
"hello"
typl> (upcase "hello")
"HELLO"
```

ตัวเลขมีชนิดดังนี้

- **จำนวนเต็ม** มีชนิด `int` ไม่มีขีดจำกัดบนของขนาด
- **ทศนิยม** มีชนิด `f64` เขียนด้วยจุดทศนิยม เช่น `1.5` หรือ `2.0`
- ไม่สามารถผสม `int` กับ `f64` ในการคำนวณเดียวกันได้ `(+ 1 2.0)` เป็นข้อผิดพลาดของชนิด หากต้องการแปลง
  ให้เขียน `(as f64 1)`

```
typl> (* 123456789012345 123456789012345)
15241578753238669120562399025
typl> (/ 7 2)
3
typl> (/ 7.0 2.0)
3.5
```

`/` กับจำนวนเต็มสองจำนวนให้จำนวนเต็มที่ตัดเศษทิ้ง (ไม่ได้สร้างเศษส่วนอย่างที่ Common Lisp ทำ)
ใช้ `(mod 7 2)` สำหรับเศษที่เหลือ

ค่าบูลีนคือ `true` และ `false`

```
typl> (> 3 2)
true
typl> (and (> 3 2) (< 3 2))
false
```

## 3. การนิยามฟังก์ชัน

ฟังก์ชันนิยามด้วย `defun` **ต้องเขียนชนิดของอาร์กิวเมนต์และชนิดของค่าที่คืนเสมอ**

```lisp
(defun square ((n int)) int
  (* n n))
```

- `(n int)` หมายถึง "อาร์กิวเมนต์ `n` ชนิด `int`" หากมีหลายอาร์กิวเมนต์ ให้เรียงต่อกัน:
  `((a int) (b int))`
- `int` หลังรายการอาร์กิวเมนต์คือชนิดของค่าที่คืน
- ค่าของนิพจน์สุดท้ายในตัวเนื้อหาคือค่าที่ฟังก์ชันคืน ไม่ต้องเขียน
  `return`

```
typl> (defun square ((n int)) int (* n n))
typl> (square 12)
144
typl> (square "a")
error: <stdin>:1:9: type error: type mismatch: expected `int`, found `string`
```

การเรียกที่ชนิดไม่ตรงกันจะถูกรายงานเป็นข้อผิดพลาดของชนิด **ก่อนที่จะรัน** เมื่อรันไฟล์
ข้อผิดพลาดของชนิดเพียงจุดเดียวที่ใดก็ตามหมายความว่าโปรแกรมจะไม่รันแม้แต่บรรทัดเดียว

หากต้องการให้อาร์กิวเมนต์เป็นทางเลือก ให้ใช้ `&optional` หากกำหนดค่าเริ่มต้น อาร์กิวเมนต์จะมี
ค่านั้นเมื่อถูกละไว้

```lisp
(defun greet ((name string) &optional (greeting string "Hello")) string
  (format false "~a, ~a!" greeting name))
```

```
typl> (greet "Ann")
"Hello, Ann!"
typl> (greet "Ann" "Hi")
"Hi, Ann!"
```

`false` ที่ให้เป็นอาร์กิวเมนต์แรกของ `format` หมายถึง "คืนผลลัพธ์เป็นสตริงแทนที่จะ
พิมพ์" `~a` แต่ละตัวถูกแทนที่ด้วยอาร์กิวเมนต์ถัดไป

## 4. ตัวแปร

ตัวแปรท้องถิ่นสร้างด้วย `let`

```lisp
(defun sum-of-squares ((a int) (b int)) int
  (let ((aa (square a))
        (bb (square b)))
    (+ aa bb)))
```

- ชนิดของตัวแปร `let` ได้มาจากค่าเริ่มต้นของมัน ไม่ต้องเขียน
- ตัวแปรของ `let` เดียวกันอ้างถึงกันไม่ได้ หากต้องการสร้างตัวแปรหนึ่งจากตัวก่อนหน้า
  ให้ใช้ `let*`

```
typl> (let* ((a 1) (b (+ a 1))) (* a b))
2
```

หากต้องการเปลี่ยนค่าของตัวแปร ให้ใช้ `setf` **การกำหนดค่าไม่สามารถเปลี่ยนชนิดของตัวแปรได้**

```
typl> (let ((x 1)) (setf x "a"))
error: <stdin>:1:22: type error: type mismatch: expected `int`, found `string`
```

ตัวแปรโกลบอลนิยามด้วย `defvar` ในกรณีนี้ต้องเขียนชนิด

```lisp
(defvar (counter int) 0)
```

## 5. เงื่อนไข

### if

เขียน `(if เงื่อนไข นิพจน์-then นิพจน์-else)` **ไม่สามารถละนิพจน์ else ได้**

```lisp
(defun sign ((n int)) string
  (if (< n 0) "negative" "non-negative"))
```

- มีเพียงนิพจน์ชนิด `bool` เท่านั้นที่เป็นเงื่อนไขได้ การเขียนตัวเลขอย่าง `(if 0 ...)` เป็น
  ข้อผิดพลาดของชนิด
- นิพจน์ then และ else ต้องมีชนิดเดียวกัน

เมื่อไม่ต้องการให้เกิดอะไรในกรณีที่เป็นเท็จ ให้ใช้ `when` (และ `unless` สำหรับตรงข้าม)

```lisp
(when (> n 100)
  (println "large")
  (println "really large"))
```

### cond

เมื่อมีเงื่อนไขสามข้อขึ้นไป `cond` อ่านง่ายกว่า `else` ตัวสุดท้ายถูกใช้เมื่อไม่มี
เงื่อนไขใดเป็นจริง

```lisp
(defun describe-number ((n int)) string
  (cond ((< n 0) "negative")
        ((= n 0) "zero")
        ((< n 10) "small")
        (else "large")))
```

### match

หากต้องการแตกกิ่งตามรูปร่างของค่า ให้ใช้ `match`

```lisp
(defun day-name ((d int)) string
  (match d
    (0 "Sun")
    (6 "Sat")
    (_ "weekday")))
```

`_` จับคู่กับค่าใดก็ได้ เนื่องจาก `int` มีค่านับไม่ถ้วน การละกิ่ง `_` เป็นข้อผิดพลาดที่บอกว่า
ไม่ครอบคลุมทุกกรณี จุดที่ `match` โดดเด่นจริง ๆ คือการแยกส่วนประกอบของ `Option` และชนิดที่คุณ
นิยามเอง ซึ่งจะกล่าวถึงในบทถัดไป [พื้นฐานของชนิด](types.md)

## 6. ลูป

ฟังก์ชันเรียกตัวเองได้

```lisp
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))
```

```
typl> (fact 30)
265252859812191058636308480000000
```

สำหรับการทำซ้ำตามจำนวนครั้งที่กำหนด ให้ใช้ `dotimes` `i` ไล่จาก 0 ถึง `n - 1`

```lisp
(defun sum-to ((n int)) int
  (let ((total 0))
    (dotimes (i (+ n 1))
      (setf total (+ total i)))
    total))
```

```
typl> (sum-to 100)
5050
```

ยังมี `while`, `do` และ `loop` แบบขยายจาก Common Lisp คำอนุประโยคของ `loop` แบบขยาย
เขียนเป็นคีย์เวิร์ด (`:for`, `:collect` และอื่น ๆ)

```
typl> (loop :for i :from 1 :to 5 :collect (* i i))
#<vector<int> 1 4 9 16 25>
```

## 7. ลิสต์และ Vector

### Vector

หากต้องการเก็บลำดับของค่าที่เป็นชนิดเดียวกัน ให้ใช้ `Vector<T>` `T` คือชนิดของสมาชิก

```lisp
(let ((v (the Vector<int> (Vector::new))))
  (push v 3)
  (push v 1)
  (push v 2)
  (println "~a" v))
;; prints #<vector<int> 3 1 2>
```

- `(Vector::new)` เพียงอย่างเดียวไม่กำหนดชนิดของสมาชิก ดังนั้นให้ระบุชนิดด้วย
  `(the Vector<int> ...)`
- `(push v x)` ต่อท้าย, `(get v i)` อ่านสมาชิกตัวที่ `i` และ `(len v)` ให้ความยาว
- `get` ที่ดัชนีเกินช่วงจะหยุดโปรแกรมพร้อมข้อผิดพลาด

### lambda และฟังก์ชันอันดับสูง

ฟังก์ชันนิรนามสร้างด้วย `lambda` เช่นเดียวกับ `defun` คุณเขียนชนิดของอาร์กิวเมนต์และค่าที่คืน

```
typl> ((lambda ((x int)) int (* x 2)) 21)
42
```

`map`, `filter`, `sort`, `foldl` และพวกเดียวกันรับ `Vector` ที่แปลงเป็น **ตัววนซ้ำ (iterator)** ด้วย
`(iter v)` คอลเลกชันมาก่อนและฟังก์ชันมาทีหลัง `v` ในตัวอย่างถัดไปคือ
`Vector` ของ `3 1 2` ที่สร้างไว้ข้างต้น

```lisp
(map (iter v) (lambda ((x int)) int (* x 10)))                 ; => #<vector<int> 30 10 20>
(filter (iter v) (lambda ((x int)) bool (> x 1)))              ; => #<vector<int> 3 2>
(sort (iter v) (lambda ((a int) (b int)) bool (< a b)))        ; => #<vector<int> 1 2 3>
(foldl (iter v) (lambda ((acc int) (x int)) int (+ acc x)) 0)  ; => 6
```

หากต้องการประมวลผลสมาชิกทีละตัว ให้ใช้ `doiter`

```lisp
(doiter (x (iter v))
  (println "item ~a" x))
```

ฟังก์ชันที่รับฟังก์ชันเป็นอาร์กิวเมนต์เขียนชนิดของอาร์กิวเมนต์นั้นเป็น
`(fn (ชนิดของอาร์กิวเมนต์...) ชนิดของค่าที่คืน)` ฟังก์ชันที่นิยามด้วย `defun` ส่งด้วยชื่อของมัน
เป็นค่าได้

```lisp
(defun twice ((f (fn (int) int)) (x int)) int
  (f (f x)))

(twice square 3)                                ; => 81
(twice (lambda ((x int)) int (* x 3)) 2)        ; => 18
```

### ลิสต์ (S-expression)

ลิสต์ที่สร้างด้วย `'(1 2 3)` หรือ `(list 1 2 3)` เป็น **ข้อมูล S-expression** สมาชิกของมันไม่จำเป็น
ต้องมีชนิดเดียวกัน

```
typl> '(1 2 3)
(1 2 3)
typl> (list 1 "two" 'three)
(1 "two" three)
```

ข้อมูล S-expression ใช้หลัก ๆ เพื่อจัดการกับตัวโปรแกรมเอง ในแมโคร ([แมโคร](macros.md)) และ
กับ `read` สำหรับข้อมูลที่สมาชิกมีชนิดที่ทราบแน่ชัด ให้ใช้ `Vector<T>` ลิสต์ S-expression
เดินผ่านได้ด้วย `dolist`

```lisp
(dolist (x '(1 2 3))
  (println "x=~a" x))
```

คู่ของสองค่าสร้างด้วย `cons` และแยกด้วย `car` และ `cdr`

```
typl> (let ((p (cons "age" 42))) (cdr p))
42
```

## 8. การเขียนโปรแกรมในไฟล์

โปรแกรมเขียนในไฟล์ (นามสกุล `.typl`) และรันด้วย `typl ชื่อไฟล์` ได้
ใช้ `println` เพื่อแสดงผลลัพธ์

```lisp
;; hello.typl
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))

(dotimes (i 5)
  (println "~a! = ~a" i (fact i)))
```

```sh
$ typl hello.typl
0! = 1
1! = 1
2! = 2
3! = 6
4! = 24
```

- `println` พิมพ์โดยใช้คำสั่งรูปแบบเดียวกับ `format` และจบด้วยการขึ้นบรรทัดใหม่ `print` ไม่
  เพิ่มการขึ้นบรรทัดใหม่
- `~a` ฝังค่าในรูปแบบที่มนุษย์อ่านได้ และ `~s` ในรูปแบบที่อ่านกลับได้ (สตริงจะมี
  `"`)
- ไฟล์ถูกอ่านจากบนลงล่าง **เรียกฟังก์ชันก่อนการนิยามของมันไม่ได้**
