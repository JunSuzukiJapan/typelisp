# แมโคร

แมโครคือฟังก์ชันที่รับโปรแกรมและคืนโปรแกรม แมโครทำให้คุณสร้างไวยากรณ์ใหม่
ที่ฟังก์ชันแสดงไม่ได้ แมโครของ typelisp ทำงานเหมือน `defmacro` ของ Common Lisp บทนี้
สมมติว่าคุณอ่าน "ลิสต์ (S-expression)" ใน[เริ่มต้นใช้งาน](intro.md)แล้ว

## 1. แมโครต่างจากฟังก์ชันอย่างไร

ฟังก์ชันรับอาร์กิวเมนต์ **หลังจากที่ถูกประเมินค่าแล้ว** แมโครรับอาร์กิวเมนต์ **เป็น
นิพจน์ก่อนการประเมินค่า** (เป็นข้อมูล S-expression) สร้างนิพจน์อื่นและคืนค่านั้น
นิพจน์ที่คืนมาแทนที่การเรียกแมโคร และหลังจากนั้นจึงถูกตรวจสอบชนิดและรัน การแทนที่นี้
เรียกว่า **การขยาย (expansion)**

ตัวอย่างเช่น ไวยากรณ์อย่าง `unless` เขียนเป็นฟังก์ชันไม่ได้ ถ้าเป็นฟังก์ชัน ตัวเนื้อหา
จะถูกประเมินค่าก่อนแม้เมื่อเงื่อนไขเป็นจริง

## 2. `defmacro` และ quasiquote

ลองสร้าง `my-unless` ที่รันตัวเนื้อหาเฉพาะเมื่อเงื่อนไขเป็นเท็จ

```lisp
(defmacro my-unless (test &rest body)
  `(if ,test () (progn ,@body ())))
```

- อาร์กิวเมนต์ของแมโครไม่เขียนชนิด ทุกอาร์กิวเมนต์เป็นข้อมูล S-expression
- `&rest body` รับอาร์กิวเมนต์ที่เหลือรวมกันเป็นลิสต์เดียว
- นิพจน์ที่ขึ้นต้นด้วย `` ` `` (quasiquote) ถูกสร้างเป็นข้อมูลตามที่เขียน ภายในนั้น:
  - `,test` แทรกเนื้อหาของตัวแปร `test` ที่ตำแหน่งนั้น
  - `,@body` ต่อสมาชิกของลิสต์ `body` เข้าไปที่ตำแหน่งนั้น

```lisp
(my-unless (> 1 2)
  (println "one")
  (println "two"))
;; one
;; two
```

คุณตรวจสอบการขยายได้ด้วย `macroexpand-1` เมื่อเขียนแมโคร การดูการขยายของมันก่อนเป็นวิธีที่เร็วที่สุด

```
typl> (macroexpand-1 '(my-unless (> 1 2) (println "one")))
(ok (if (> 1 2) () (progn (println "one") ())))
```

## 3. การขยายก็ถูกตรวจสอบชนิดเช่นกัน

นิพจน์ที่แมโครคืนมาถูกตรวจสอบชนิดเหมือนนิพจน์ที่คุณเขียนด้วยมือ

```
typl> (defmacro add-a (x) `(+ ,x "a"))
typl> (add-a 1)
error: <stdin>:1:1: type error: type mismatch: expected `int`, found `string`
```

ข้อผิดพลาดถูกรายงานที่ตำแหน่งที่เรียกแมโคร

กฎที่ว่าไม่สามารถละกิ่ง else ของ `if` ได้ และทั้งสองกิ่งของ `if` ต้องมีชนิด
เดียวกัน ใช้กับการขยายตามที่เป็น `my-unless` ข้างต้นลงท้ายด้วย
`(progn ,@body ())` เพื่อให้ ไม่ว่านิพจน์สุดท้ายของตัวเนื้อหาจะมีชนิดใด ทั้งสองกิ่งของ
`if` มีชนิด `()`

## 4. การชนกันของชื่อและ `gensym`

แมโครแบบตรงไปตรงมาที่สลับค่าของตัวแปรสองตัวมีหน้าตาแบบนี้:

```lisp
(defmacro swap-bad (a b)
  `(let ((tmp ,a))
     (setf ,a ,b)
     (setf ,b tmp)))
```

ส่วนใหญ่ใช้ได้ แต่พังเมื่อตัวแปรของผู้เรียกบังเอิญชื่อ `tmp`

```lisp
(let ((tmp 1) (other 2))
  (swap-bad tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=1 other=2   (not swapped)
```

การขยายคือ `(let ((tmp tmp)) (setf tmp other) (setf other tmp))` และ `tmp` ที่แมโครสร้างขึ้น
บัง `tmp` ของผู้เรียก

เพื่อหลีกเลี่ยงปัญหานี้ ให้สร้างชื่อของตัวแปรที่ใช้ภายในแมโครด้วย `gensym` `gensym` คืน
สัญลักษณ์ใหม่ที่ไม่สามารถเขียนที่ใดในโปรแกรมได้

```lisp
(defmacro swap (a b)
  (let ((tmp (gensym "tmp")))
    `(let ((,tmp ,a))
       (setf ,a ,b)
       (setf ,b ,tmp))))
```

```lisp
(let ((tmp 1) (other 2))
  (swap tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=2 other=1
```

เช่นเดียวกับ Common Lisp แมโครของ typelisp ไม่ป้องกันการชนกันของชื่ออัตโนมัติ (เป็นแบบ unhygienic)
จำไว้ว่า: **ใช้ `gensym` สำหรับการผูกที่แมโครสร้างขึ้น**

ในทำนองเดียวกัน แมโครที่ทำซ้ำตัวเนื้อหาตามจำนวนครั้งที่กำหนดเขียนได้ดังนี้:

```lisp
(defmacro repeat (n &rest body)
  (let ((i (gensym "i")))
    `(dotimes (,i ,n) ,@body)))

(repeat 3 (println "hi"))
```

## 5. การขยายต่างกันตามอาร์กิวเมนต์

ตัวเนื้อหาของแมโครเป็นโค้ด typelisp ธรรมดา จึงตรวจสอบอาร์กิวเมนต์ด้วย `if` หรือ `match` และ
สร้างการขยายที่ต่างกันได้ อาร์กิวเมนต์เป็นข้อมูล S-expression (`Option<Sexpr>`) และลิสต์ว่าง
คือ `none`

ลองสร้าง `my-and` ที่คืน `true` หากทุกเงื่อนไขเป็นจริง

```lisp
(defmacro my-and (&rest forms)
  (match forms
    ((none) 'true)                                    ; no arguments
    ((cons f more)
     (if (sexpr-null more)
         f                                            ; just one
         `(if ,f (my-and ,@more) false)))             ; two or more
    (_ (panic "my-and: not a list"))))

(my-and (> 2 1) (> 3 2))      ; => true
(my-and (> 2 1) (> 1 3))      ; => false
```

- `(cons f more)` เป็นรูปแบบที่ดึงส่วนหัวของลิสต์ไปไว้ใน `f` และส่วนที่เหลือไว้ใน `more`
- `sexpr-null` ทดสอบว่าข้อมูล S-expression เป็นลิสต์ว่างหรือไม่
- กิ่ง `_` สุดท้ายจำเป็นเพราะข้อมูล S-expression มีรูปแบบอื่นนอกจากลิสต์ (ตัวเลข
  สตริง และอื่น ๆ) และ `match` ต้องการให้ครอบคลุมสิ่งเหล่านั้นด้วย อาร์กิวเมนต์ `&rest` เป็น
  ลิสต์เสมอ ดังนั้นกิ่งนี้จึงไม่เคยรันจริง
- แมโครเรียกตัวเองในการขยายของมันได้ การขยายทำซ้ำจนไม่เหลือการเรียกแมโคร

## 6. อาร์กิวเมนต์ทางเลือก

`&optional` รับอาร์กิวเมนต์ที่ละได้ กำหนดค่าเริ่มต้นได้

```lisp
(defmacro inc-by (place &optional (n 1))
  `(setf ,place (+ ,place ,n)))

(let ((c 10))
  (inc-by c)
  (inc-by c 5)
  c)                            ; => 16
```

`&key` รับอาร์กิวเมนต์แบบคีย์เวิร์ด
([เอกสารอ้างอิงไวยากรณ์ 3.14](../reference/syntax.md#314-defmacro--การนิยามแมโคร))

## 7. `macrolet`: แมโครสำหรับที่เดียว

แมโครที่ใช้เฉพาะภายในนิพจน์เดียวนิยามด้วย `macrolet` ได้ ภายนอกมองไม่เห็น

```lisp
(macrolet ((sq (x) `(* ,x ,x)))
  (+ (sq 3) (sq 4)))            ; => 25
```

## 8. สิ่งที่ควรจำ

- **เรียกแมโครได้หลังจากการนิยามเท่านั้น** เช่นเดียวกับฟังก์ชัน ให้นิยามไว้ใกล้ต้น
  ไฟล์
- ทำให้แมโครใช้ได้กับโมดูลอื่นด้วย `(pub defmacro ...)`
- ไวยากรณ์มาตรฐานจำนวนมาก รวมถึง `when`, `unless`, `cond`, `and`, `or` และ `dotimes` นิยาม
  เป็นแมโคร คุณดูสิ่งที่อยู่ข้างในได้ด้วย `(macroexpand '(when true 1))`
- หากเขียนเป็นฟังก์ชันได้ ให้เขียนเป็นฟังก์ชัน แมโครส่งเป็นค่าไม่ได้
  และต้องอ่านการขยายของมันจึงจะเข้าใจว่ามันทำอะไร
