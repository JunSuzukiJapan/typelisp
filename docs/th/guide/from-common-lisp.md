# สำหรับโปรแกรมเมอร์ Common Lisp

typelisp สืบทอดไวยากรณ์และชื่อฟังก์ชันจำนวนมากของ Common Lisp (CL) แต่เป็นภาษาที่มี
ระบบชนิดแบบสถิต ด้วยเหตุนี้โค้ด CL จึงไม่ได้ทำงานตามที่เขียนไว้เสมอไป คู่มือนี้
รวบรวมจุดที่ผู้คุ้นเคยกับ CL มักสะดุด พร้อมวิธีเขียนโค้ดใหม่

## 1. ไม่มี `nil` หรือ `t`

ค่าบูลีนคือ `true` และ `false` ไม่มีการนิยาม `nil` และ `t`

```lisp
(if (> x 0) "pos" "non-pos")
(defvar (debug bool) false)
```

- **มีเพียง `bool` เท่านั้นที่เป็นเงื่อนไขได้** การเขียน `0` หรือลิสต์ว่างเป็นเงื่อนไขเป็นข้อผิดพลาดของชนิด
  ไม่มีกฎที่ว่า "ทุกอย่างที่ไม่ใช่ nil เป็นจริง"
- **ไม่สามารถละกิ่ง else ของ `if` ได้** `(if c x)` เป็นข้อผิดพลาด เมื่อไม่ต้องการกิ่ง else
  ให้ใช้ `when` / `unless`
- **"ไม่มีค่า" แสดงด้วย `Option<T>`** ฟังก์ชันที่ใน CL คืน nil เพื่อหมายถึง "ไม่พบ"
  ในที่นี้จะคืน `(some x)` หรือ `none`

  ```lisp
  (match (position 3 (iter v))
    ((some i) (println "found at ~a" i))
    ((none) (println "not found")))
  ```

- ลิสต์ว่าง `()` ขึ้นกับบริบท อาจเป็นค่าของชนิด Unit (ค่าที่ฟังก์ชันซึ่งไม่คืนอะไรคืนมา)
  หรือลิสต์ว่างของข้อมูล S-expression ก็ได้ เป็นค่าที่ต่างจาก `false`

## 2. การเขียนชนิด

อาร์กิวเมนต์และค่าที่คืนของฟังก์ชันต้องมีชนิด

```lisp
(defun area ((w i32) (h i32)) i32
  (* w h))

(defun first-or<T> ((v Vector<T>) (default T)) T      ; a generic function
  (unwrap-or (first (iter v)) default))
```

- การนิยามที่ไม่มีชนิด เช่น `(defun f (x) x)` เขียนไม่ได้
- ตัวแปรโกลบอลอย่าง `defvar` ก็ต้องมีชนิด: `(defvar (count int) 0)`
- `the` ไม่ใช่การตรวจสอบตอนรัน แต่เป็นคำอธิบายประกอบสำหรับตัวตรวจสอบชนิด
- **ไม่มีวิธีตรวจสอบชนิดตอนรัน** ไม่มี `typep` หรือ `type-of` เพราะ
  ชนิดของทุกค่าถูกกำหนดตอนคอมไพล์ หากต้องการรับได้หลายชนิด ให้สร้าง sum type ด้วย
  `defenum` หรือใช้ trait
- `deftype` นิยามชื่อแทนของชนิด (type alias) ชนิดที่อธิบายช่วงของค่า เช่น
  `(deftype small () '(integer 0 9))` สร้างไม่ได้

ชนิดจำนวนเต็มเริ่มต้น `int` มีความแม่นยำไม่จำกัด เช่นเดียวกับ integer ของ CL ไม่มีขีดจำกัดบนของ
ขนาด ชนิดที่มีความกว้างคงที่ `i8` ถึง `i32` และ `u8` ถึง `u32` ก็มีอยู่ แต่ไม่มีชนิดจำนวนเต็ม
ความกว้างคงที่ 64 บิต

## 3. ฟังก์ชันเป็นค่า

typelisp ไม่แยกเนมสเปซของฟังก์ชันกับตัวแปร ชื่อของฟังก์ชันส่งเป็นค่าได้ตามที่เป็น
ไม่มี `#'` และไม่มี `funcall`

```lisp
(defun twice ((x int)) int (* 2 x))
(defun apply-to ((f (fn (int) int)) (x int)) int
  (f x))                                  ; call it directly, not with funcall

(apply-to twice 5)                        ; twice, not #'twice
```

- ฟังก์ชันที่มีให้ในตัวอย่าง `+` และ `1+` ก็ส่งเป็นค่าได้ตามที่เป็น ในที่ที่ชนิดของ
  อาร์กิวเมนต์ถูกกำหนดไว้ เช่น `(fn (int) int)` เมื่อส่งให้ฟังก์ชัน generic เช่น
  `foldl` หรือ `map` จะไม่ทราบว่าหมายถึง `+` ของชนิดใด จึงให้ห่อด้วย `lambda`

  ```lisp
  (apply-to 1+ 5)                                          ; => 6
  (foldl (iter v) (lambda ((acc int) (x int)) int (+ acc x)) 0)
  ```

- ฟังก์ชันของลำดับรับ **คอลเลกชันก่อนและฟังก์ชันทีหลัง**: `(map it f)`,
  `(filter it f)`, `(foldl it f init)` ซึ่งตรงข้ามกับ `(mapcar f list)` ของ CL
- `lambda` ใช้ `&optional` หรือ `&key` ไม่ได้ (ใช้ `&rest` ได้)
- **เรียกฟังก์ชันก่อนที่จะนิยามไม่ได้** ใน CL คุณเรียกฟังก์ชันที่นิยามทีหลังได้ แต่ที่นี่
  จะเกิด `no such function` สำหรับฟังก์ชันที่เรียกกันเองแบบวนกลับ ให้ประกาศตัวหนึ่ง
  ด้วย `defsignature` ก่อน

  ```lisp
  (defsignature odd2 (i32) bool)
  (defun even2 ((n i32)) bool (if (= n 0) true (odd2 (- n 1))))
  (defun odd2 ((n i32)) bool (if (= n 0) false (even2 (- n 1))))
  ```

## 4. ลิสต์และ Vector

สิ่งที่สอดคล้องกับลิสต์ของ CL คือ **ข้อมูล S-expression** ซึ่งมีชนิด `Option<Sexpr>` (ลิสต์ว่าง
คือ `none`) `(list 1 2 3)` และ `'(a b c)` มีชนิดนี้ ข้อมูล S-expression เป็นสิ่งที่แมโครและ
`read` ทำงานด้วย สำหรับที่เก็บข้อมูลทั่วไป ให้ใช้ **`Vector<T>`**

| สิ่งที่ต้องการ | CL | typelisp |
|---|---|---|
| ส่วนหัวและส่วนที่เหลือของ S-expression | `(car xs)` `(cdr xs)` | `(sexpr-car xs)` `(sexpr-cdr xs)` |
| เดินผ่านลิสต์ S-expression | `(dolist (x xs) ...)` | เหมือนกัน |
| ลำดับของสมาชิกที่เป็นชนิดเดียวกัน | ลิสต์หรือเวกเตอร์ | `Vector<T>` |
| คู่ (pair) | `(cons a b)` | `(cons a b)` (ชนิดคือ `cons-cell<A,B>`) |
| การแมป | `(mapcar f xs)` | `(map (iter v) f)` |

`car` / `cdr` เป็นตัวเข้าถึงของคู่ `cons-cell<A,B>` ที่สร้างด้วย `cons` ใช้กับ
ลิสต์ S-expression ไม่ได้

`Vector` เขียนด้วย `#(..)` เหมือนเวกเตอร์ใน CL และพิมพ์ออกมาเป็น `#(..)` เช่นกัน:

```lisp
(let ((v #(1 2)))
  (push v 3)
  (map (iter v) (lambda ((x int)) int (* x 10))))   ; => #(10 20 30)
```

มีความต่างจาก CL สามข้อ สมาชิกทุกตัวต้องมีชนิดเดียวกัน (`#(1 "a")` เป็นข้อผิดพลาดของชนิด) การประเมินค่าแต่ละครั้งสร้างเวกเตอร์ใหม่ การแก้ไขจึงไม่กระทบการประเมินค่าครั้งถัดไป (ใน CL ผลของการแก้ไขลิเทอรัลไม่ได้นิยามไว้) `#()` ที่ว่างต้องระบุชนิด เช่น `(the Vector<int> #())` อาร์เรย์หลายมิติเขียนเป็น `#2A((1 2) (3 4))` เหมือน CL

ฟังก์ชันของลำดับอย่าง `map`, `filter`, `sort` และ `find` ทำงานกับค่าที่ implement trait
`Iter` ให้ส่ง `Vector` หลังจากแปลงเป็นตัววนซ้ำด้วย `(iter v)`

## 5. ไม่มีค่าหลายค่า

ไม่มี `values` และไม่มี `multiple-value-bind` ฟังก์ชันที่คืนหลายค่าใน CL จะคืน
คู่หรือ struct

| CL | typelisp |
|---|---|
| `(floor 7 2)` → 3, 1 | `(floor-div 7 2)` → `cons-cell` ที่ `car` เป็น 3 และ `cdr` เป็น 1 |
| `(decode-universal-time t)` → 9 ค่า | struct `decoded-time` |
| `(read-from-string s)` → ค่า, ตำแหน่ง | `(read-from-string s)` คืน `cons-cell` ของค่าและตำแหน่งภายใน `Result` หากต้องการเฉพาะค่า ใช้ `(read s)` |

## 6. ไม่มีตัวแปรพิเศษ (dynamic binding)

`let` ผูกแบบ lexical เสมอ หากคุณผูกตัวแปรที่นิยามด้วย `defvar` ใหม่ด้วย `let` ฟังก์ชันที่
เรียกจากตรงนั้นก็ยังเห็นค่าเดิม

```lisp
(defvar (*depth* int) 1)
(defun show () () (println "~a" *depth*))
(let ((*depth* 2)) (show))       ; 2 in CL, 1 in typelisp
```

หากต้องการเปลี่ยนตัวแปรควบคุมอย่าง `*print-base*` ชั่วคราว ให้ใช้ `dlet` มันกำหนดค่า
และคืนค่าเดิมไม่ว่าจะออกจากตัวเนื้อหาด้วยวิธีใด

```lisp
(dlet ((*print-base* 16))
  (format false "~a" 255))       ; => "ff"
```

`dlet` เขียนทับตัวแปรโกลบอลเอง จึงไม่ใช่การผูกต่อเธรด

## 7. ไม่ใช้ระบบ condition

ไม่มี `define-condition`, `handler-case`, `handler-bind`, `restart-case`, `error` หรือ `signal`
สิ่งเหล่านี้เข้ากับระบบชนิดแบบสถิตได้ไม่ดี แทนที่จะเป็นเช่นนั้น ใช้สองอย่างนี้สำหรับจุดประสงค์ที่ต่างกัน:

- **ความล้มเหลวที่กู้คืนได้คืน `Result<T,E>`** ผู้เรียกแยก `ok` / `err` ด้วย `match`
  ไม่มีทางลัดอย่าง `?` ของ Rust

  ```lisp
  (match (parse-int "42x")
    ((ok n) n)
    ((err e) (progn (println "bad input: ~a" (message e)) 0)))
  ```

- **ความล้มเหลวที่กู้คืนไม่ได้ (บั๊ก) คือ `panic`** `(panic "message")`, การส่ง `none` ให้ `unwrap`,
  การหารด้วย 0 และดัชนีที่เกินช่วงเป็นกรณีประเภทนี้ และโปรแกรมจะหยุด การล้างทรัพยากรของ
  `unwind-protect` จะรันก่อนหยุด

ชนิดข้อผิดพลาดรวมเป็นหนึ่งเดียวด้วย trait `Error` และ `(message e)` ให้ข้อความ วิธีสร้าง
ชนิดข้อผิดพลาดของคุณเองอยู่ใน
[Option, Result และชนิดข้อผิดพลาด](../reference/functions/option-result.md#3-ชนิดข้อผิดพลาดและ-trait-error)
`assert` และ `warn` ใช้ได้เหมือนใน CL

`catch` / `throw` / `unwind-protect` มีอยู่ แต่แท็กของ `catch` จำกัดเฉพาะสัญลักษณ์ literal ที่ไม่ถูก
ประเมินค่า (`'done`) และค่าที่โยนด้วยแท็กเดียวกันต้องมีชนิดเดียว

## 8. ไม่มี CLOS

ไม่มี `defclass`, `defgeneric` หรือ method combination

- ชนิดข้อมูลนิยามด้วย `defstruct` (struct) และ `defenum` (sum type)
- `defmethod` นิยามเมทอดที่เป้าหมายถูกตัดสินจาก **ชนิดสถิตของอาร์กิวเมนต์แรก**
  เท่านั้น ไม่มี multiple dispatch
- หากต้องการให้การดำเนินการร่วมกันข้ามชนิด ให้ใช้ trait (`deftrait` / `impl`) สำหรับค่าที่
  ชนิดจริงถูกตัดสินตอนรัน ให้ใช้ชนิด `:dyn Trait`
  ([เอกสารอ้างอิงไวยากรณ์ 3.9](../reference/syntax.md#39-deftrait--impl--trait))

`defstruct` ต่างออกไปอย่างไร:

- ตัวสร้างคือ `TypeName::new`: `(point::new 1 2)` หากต้องการชื่ออย่าง `make-point`
  ตัวเลือก `(:constructor make-point)` จะสร้างให้
- นอกจาก `(x p)` แล้ว ตัวเข้าถึงเขียนเป็น `p::x` ได้ เปลี่ยนด้วย `(setf p::x 5)`
- ไม่สร้าง predicate (`point-p`) ไม่มี `:conc-name`, `:type` หรือ `:named`
- `:include` สืบทอดเฉพาะ slot เท่านั้น ชนิดไม่ได้เป็นชนิดย่อยของชนิดแม่

## 9. โมดูลแทนแพ็กเกจ

ไม่มีแพ็กเกจ เนมสเปซคือโมดูล และไฟล์เป็นโมดูลในตัวเอง แทนที่จะเขียน
`pkg:symbol` ให้เขียน `module::name` และนำชื่อเข้ามาด้วย `use`
([โมดูลและการจัดวางไฟล์](modules.md))

คีย์เวิร์ด `:foo` มีอยู่และเป็นสัญลักษณ์ที่ประเมินค่าเป็นตัวเอง เนื่องจากไม่มีแพ็กเกจ
เครื่องหมายทวิภาคจึงเป็นส่วนหนึ่งของชื่อ: `(symbol->string :foo)` คืน `":foo"`

## 10. ความแตกต่างในการอ่านและไวยากรณ์

- ไม่แยกตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก (สัญลักษณ์กลายเป็นตัวพิมพ์เล็กเมื่ออ่าน) เหมือน
  กับ CL
- ไม่มี `#'` (หัวข้อ 3) literal จำนวนเชิงซ้อน `#c(...)` อ่านไม่ได้ ให้สร้างจำนวนเชิงซ้อน
  ด้วย `(complex 1.0 2.0)`
- อนุประโยคของ `loop` แบบขยายเขียนด้วยคีย์เวิร์ด: `(loop :for i :from 1 :to 3 :collect i)`
  `loop` ที่ไม่ได้ขึ้นต้นด้วยคีย์เวิร์ดเป็นลูปไม่รู้จบแบบง่าย ออกด้วย `(break)` หรือ
  `(return value)` `return` ออกจากลูปในสุด (หากต้องการออกจากฟังก์ชัน ให้ใช้ `return-from`)
- ปลายทางของ `format` คือ `false` (คืนสตริง), `true` (เอาต์พุตมาตรฐาน) หรือสตรีม
  คำสั่งรูปแบบ (format directive) เหมือนกับใน CL
- การอ่านจากสตริงคือ `(read "...")` และการอ่านจากสตรีมคือ `(read-sexpr s)` ทั้งสองคืน
  `Result`
- `eval` ตรวจสอบชนิดของนิพจน์ที่ให้ก่อนประเมินค่า และคืน `Result` การอ้างอิงล่วงหน้า
  ทำไม่ได้ เช่นเดียวกับในซอร์สโค้ด
- ไม่มี `eval-when`
- ชื่อฟังก์ชันไม่ใช้ส่วนท้าย `?` หรือ `!` predicate ตั้งชื่อด้วย `-p` / `p` เหมือนใน CL
  (`zerop`, `sexpr-null`) หรือใช้ `is-` นำหน้า (`is-some`)

## 11. ฟังก์ชันหลักที่ชื่อต่างกัน

| CL | typelisp |
|---|---|
| `string-upcase` / `string-downcase` | `upcase` / `downcase` |
| `read` (จากสตรีม) | `read-sexpr` |
| `pathname` | `to-pathname` |
| `floor` และพวกที่รับสองอาร์กิวเมนต์ | `floor-div` `ceiling-div` `round-div` `truncate-div` |
| `mapcar` | `map` (ลำดับอาร์กิวเมนต์กลับกัน; หัวข้อ 4) |
| `length` (ของเวกเตอร์) | `len` |
| `hash-table-count` | `count` / `size` |

รายการฟังก์ชันอยู่ใน[ฟังก์ชันที่มีให้ในตัว](../reference/functions/README.md)

## 12. สิ่งอื่นที่ไม่มี

- `progv`, `symbol-function`, `symbol-value`
- `*readtable*` และ `copy-readtable`, `readtable-case` (ตัว reader macro เองนิยามได้ด้วย
  `set-macro-character`)
- logical pathname และ wildcard pathname
- `input-stream-p` / `output-stream-p` (ทิศทางของสตรีมถูกกำหนดโดยชนิดของมัน)
