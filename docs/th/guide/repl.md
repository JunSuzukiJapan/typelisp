# REPL

เมื่อเรียก `typl` โดยไม่มีอาร์กิวเมนต์ จะเข้าสู่ REPL (โหมดโต้ตอบ) เอกสารนี้อธิบายสิ่งที่ REPL
ทำได้นอกจากการประเมินนิพจน์ ได้แก่ คำสั่งของ REPL การช่วยเหลือขณะพิมพ์ การอ้างถึงผลลัพธ์ก่อนหน้า
การหยุดการคำนวณ และการตรวจสอบหลังเกิดข้อผิดพลาด

## การเริ่มและการออก

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

ออกด้วย `:quit` (ย่อว่า `:q`) หรือ `Ctrl+D` ประวัติการป้อนจะเก็บไว้ใน `~/.typl_history`
ครั้งต่อไปที่เริ่มจึงเรียกกลับมาได้ด้วย `Ctrl+P` / `Ctrl+N` หรือ `Ctrl+R` (ค้นหาในประวัติ)

เมื่อเริ่ม ก่อนพรอมต์แรกจะทำสิ่งต่อไปนี้ตามลำดับ ทุกขั้นไม่แสดงค่าที่ได้

1. เนื้อหาของ `~/.typlrc` ถ้ามีไฟล์นี้ ถ้าใส่ `--no-init` จะไม่อ่าน
2. `--eval FORM` และ `--load FILE` จากบรรทัดคำสั่ง ตามลำดับที่เขียน ใส่ได้กี่ครั้งก็ได้ทั้งสองอย่าง

```
$ typl --load util.typl --eval '(println "ready")'
ready
typl>
```

`--eval`, `--load` และ `--no-init` ใช้ได้เฉพาะตอนเริ่ม REPL ถ้าใส่ตอนรันไฟล์จะเป็นข้อผิดพลาด

REPL เริ่มที่มอดูล `user` เมื่อย้ายไปมอดูลอื่นด้วย `(in-module foo)` พรอมต์จะแสดงมอดูลนั้น

```
typl> (in-module foo)
typl user::foo>
```

## คำสั่งของ REPL

`:ชื่อ` ที่เขียนไว้ต้นบรรทัดคือคำสั่งของ REPL `:help` แสดงรายการคำสั่ง `:ชื่อ` ที่ไม่อยู่ในรายการ
ไม่ใช่คำสั่ง แต่จะประเมินเป็นคีย์เวิร์ดธรรมดา

| คำสั่ง | ความหมาย |
|---|---|
| `:help` (`:h`, `:?`) | แสดงรายการคำสั่ง |
| `:type FORM` (`:t`) | แสดงชนิดของ FORM โดยไม่ประเมิน |
| `:describe NAME` (`:d`) | แสดงประเภทของนิยาม ชนิด ฟิลด์หรือแวเรียนต์ เมธอด เทรตที่อิมพลีเมนต์ ตำแหน่งที่นิยาม และสตริงเอกสาร |
| `:apropos TEXT` | ค้นหานิยามในทุกมอดูลที่ชื่อมี TEXT (ไม่แยกตัวพิมพ์ใหญ่และเล็ก) |
| `:src NAME` | แสดงซอร์สของนิยาม |
| `:who-calls NAME` | แสดงฟังก์ชันและเมธอดที่เรียกฟังก์ชันหรือเมธอด NAME |
| `:inspect FORM` (`:i`) | ประเมิน FORM แล้วเปิดค่าตามชนิดของมัน |
| `:backtrace` (`:bt`) | แสดงการเรียกที่ยังค้างอยู่ตอนที่บรรทัดก่อนหน้าล้มเหลว เริ่มจากด้านในสุด |
| `:locals [N]` | แสดงอาร์กิวเมนต์ของการเรียกลำดับที่ N ใน `:backtrace` (ลำดับที่ 0 ถ้าไม่ใส่ N) |
| `:cd [DIR]` | ย้ายโฟลเดอร์ปัจจุบันไปที่ DIR (ไปโฮมโฟลเดอร์ถ้าไม่ใส่ DIR) |
| `:pwd` | แสดงโฟลเดอร์ปัจจุบัน |
| `:quit` (`:exit`, `:q`) | ออกจาก REPL |

NAME เป็นชื่ออย่าง `inner` หรือเป็นพาทอย่าง `std::seq::reverse` หรือ `Option::unwrap` ก็ได้

```
typl> (defun inner ((x int) (s string)) int "บวก 1 ให้ x" (+ x 1))
typl> :describe inner
user::inner is a function
  type: (fn (int string) int)
  parameters: x s
  defined at <stdin>:1:1

บวก 1 ให้ x
typl> :src inner
(defun inner ((x int) (s string)) int "บวก 1 ให้ x" (+ x 1))
```

`:src` แสดงนิยามที่โหลดจากไฟล์โดยเอามาจากไฟล์นั้น และแสดงนิยามที่พิมพ์ใน REPL โดยเอามาจากข้อความที่พิมพ์
นิยามในไลบรารีมาตรฐานไม่มีการบันทึกตำแหน่งในซอร์ส จึงแสดงซอร์สไม่ได้

`:who-calls` ค้นในเนื้อฟังก์ชันของเซสชันปัจจุบัน สำหรับฟังก์ชันเจเนริก จะพบเฉพาะการใช้ที่ถูกสร้างอินสแตนซ์ด้วยชนิดที่ระบุแล้ว

`:cd` เปลี่ยนโฟลเดอร์ที่ `(load ...)` ค้นหา แต่ `use` ยังค้นหาไฟล์ในโฟลเดอร์ที่เริ่ม REPL เหมือนเดิม

## การเปิดค่า (`:inspect`)

`:inspect` เปิดค่าตามชนิดของมัน สตรักต์เปิดเป็นฟิลด์ อีนัม (รวม `Option`) เปิดเป็นฟิลด์ของแวเรียนต์
`Vector` เปิดเป็นสมาชิก และ `HashTable` เปิดเป็นคีย์และค่า พิมพ์ตัวเลขเพื่อเข้าไปในส่วนนั้น `u`
เพื่อกลับขึ้นหนึ่งระดับ และ `q` เพื่อจบ

```
typl> (defstruct point (x int) (y Option<int>))
typl> :inspect (make-instance 'point :x 1 :y (Some 2))
(make-instance 'point :x 1 :y (Some 2)) = #<point x: 1 y: (Some 2)>
  type: point
  0. x = 1
  1. y = (Some 2)
inspect> 1
y = (Some 2)
  type: Option<int>
  0. Some 0 = 2
inspect> q
```

ลิสต์และ `Sexpr` จะไม่ถูกเปิด แต่แสดงตามที่เป็น

## การช่วยเหลือขณะพิมพ์

เมื่อพิมพ์จากเทอร์มินัล จะใช้สิ่งต่อไปนี้ได้

- `Tab` เติมชื่อ (นิยาม และไวยากรณ์อย่าง `if` และ `defun`) พาทที่มี `::` คำสั่ง REPL ที่ต้นบรรทัด
  และชื่อไฟล์เมื่ออยู่ในสตริง
- เมื่อพิมพ์ชื่อฟังก์ชันตามด้วยช่องว่าง ชนิดของฟังก์ชันนั้นจะแสดงจาง ๆ ที่ท้ายบรรทัด
- วงเล็บที่เป็นคู่ของวงเล็บข้างเคอร์เซอร์จะถูกเน้น
- ถ้ากด Enter ก่อนฟอร์มจบ บรรทัดถัดไปจะเริ่มด้วยการย่อหน้าตามจำนวนวงเล็บที่ยังเปิดอยู่

## ผลลัพธ์ก่อนหน้า (`:*`, `:**`, `:***`)

ใน REPL `:*` คือค่าที่แสดงล่าสุด `:**` คือค่าก่อนหน้านั้น และ `:***` คือค่าก่อนหน้านั้นอีก
แต่ละตัวมีชนิดตามค่าของมัน

```
typl> 1
1
typl> "a"
"a"
typl> 2
2
typl> (+ :*** :*)
3
```

- อินพุตที่ไม่ได้แสดงค่า (เช่น นิยาม) หรือที่ล้มเหลว จะไม่เลื่อนผลลัพธ์
- การเขียน `:**` หรือ `:***` ก่อนที่จะมีผลลัพธ์ครบจำนวนนั้นเป็นข้อผิดพลาด
- `':*` ที่ควอตแล้วเป็นคีย์เวิร์ดธรรมดา
- `:*` ที่เขียนในเนื้อฟังก์ชันจะยังชี้ไปที่ผลลัพธ์ ณ ตอนที่นิยามฟังก์ชัน `*` ของ Common Lisp
  อ่านค่าตอนเรียกฟังก์ชัน แต่ typelisp กำหนดไว้ตอนนิยามเพื่อให้มีชนิด
- นอก REPL (ตอนรันไฟล์ และใน `~/.typlrc`, `--load`, `--eval`) `:*` เป็นคีย์เวิร์ดธรรมดา

## การหยุดการคำนวณ (`Ctrl+C`)

ถ้ากด `Ctrl+C` ระหว่างการประเมิน การคำนวณนั้นจะหยุดและกลับสู่พรอมต์ สิ่งที่นิยามไว้ก่อนหน้ายังอยู่
ใช้ได้ทั้งกับลูปในอินเทอร์พรีเตอร์ ลูปในโค้ดที่คอมไพล์แล้ว และระหว่างรออยู่ใน `sleep` หรือ `wait`
งานเก็บกวาดของ `unwind-protect` ที่ค้างอยู่จะถูกทำ

```
typl> (loop)
^Cerror: interrupted
typl>
```

`Ctrl+C` ที่กดระหว่างพิมพ์จะแค่ทิ้งบรรทัดที่กำลังพิมพ์

## การตรวจสอบหลังเกิดข้อผิดพลาด (`:backtrace`, `:locals`)

หลังจากการประเมินหยุดเพราะข้อผิดพลาด `:backtrace` (`:bt`) จะแสดงการเรียกฟังก์ชันที่ค้างอยู่ตอนนั้น
เริ่มจากด้านในสุด `:locals N` แสดงอาร์กิวเมนต์ของการเรียกลำดับที่ N ตามชนิดที่ประกาศไว้

```
typl> (defun inner ((x int)) int (if (= x 0) (panic "boom") x))
typl> (defun outer ((n int)) int (* 2 (inner n)))
typl> (outer 0)
error: <stdin>:1:40: panic: boom
typl> :bt
  0: (user::inner 0)  called at <stdin>:1:33
  1: (user::outer 0)  called at <stdin>:1:1
typl> :locals 1
  n = 0
```

- สำหรับการเรียกจากนิพจน์สุดท้ายของฟังก์ชัน (การเรียกแบบหาง) จะไม่แสดงฟังก์ชันที่เรียก
  ด้วยเหตุนี้ลูปแบบเรียกซ้ำที่หางจึงใช้พื้นที่เท่าการเรียกครั้งเดียว ไม่ว่าจะวนกี่รอบ
- การเรียกภายในฟังก์ชันที่คอมไพล์แล้ว และฟังก์ชันนิรนาม (`lambda`) จะไม่แสดง
- `:locals` แสดงเฉพาะอาร์กิวเมนต์ ไม่แสดงตัวแปรที่ผูกด้วย `let`
- เมื่อประเมินบรรทัดถัดไป บันทึกข้อผิดพลาดก่อนหน้าจะหายไป
