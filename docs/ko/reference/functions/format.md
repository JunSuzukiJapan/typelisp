# 서식 지시자

`print`/`println`/`format`의 제어 문자열에 쓰는 지시자. CL `format`의 지시자를 거의 모두 다룬다. 함수 자체는
[출력](printing.md#1-print--println--format)에서 설명한다.

## 1. 지시자 쓰는 법

각 지시자는 `~`, 생략할 수 있는 **전치 매개변수**(쉼표로 구분: 정수 / `'c`(문자) / `v`(다음 인수에서 가져온다) /
`#`(남은 인수의 개수)), 생략할 수 있는 **수식자** `:`와 `@`, 지시자 문자의 순서로 쓴다. 지시자 문자는 대소문자를
구별하지 않는다.

제어 문자열은 리터럴이어야 한다([출력](printing.md#1-print--println--format)). 그 위에서 검사 시에 다음을 검사한다.

- **인수의 개수와 타입.** 인수를 소비하는 각 지시자에 대해 인수가 남아 있는지, 그 타입을 받는지(아래 표의 "인수"
  설명). `~*`로 이동하기, `~[`의 어느 절이 선택되는지, `~^`가 발동하는지, `~@{`가 몇 번 반복되는지처럼 경로가 실행 시의
  값에 따라 달라지는 곳은 **모든 경로**를 검사한다. 남는 인수는 상관없다(CL과 같다).
- **매개변수와 수식자.** 받지 않는 수식자, 너무 많은 매개변수, 범위를 벗어난 값(음수 폭, 2~36 이외의 기수, 문자를
  기대하는 곳의 정수 등)은 오류이다. 조용히 무시하거나 반올림하는 일은 없다.

리스트 인수(`~{`, `~:{`, `~<...~:>`)의 **요소**는 `Sexpr`이며, 그 개수도 각 요소의 타입도 타입에서는 알 수 없다. 요소에
대한 요구(`~d`에는 정수 등)와 요소의 부족은 값이 도착했을 때 검사되며 실행 시 오류가 된다(다른 표현으로 바꿔 출력하는
일은 없다).

CL의 관대한 규칙은 채택하지 않는다. `~d`에 정수가 아닌 것을 넘기면 `~a`로 출력되거나 `~:[`가 아무 값이나 진리값으로
다루는 식의 재해석은 하지 않으며, 타입 오류가 된다.

## 2. 출력(인수를 하나 소비)

| 지시자 | 매개변수 / 수식자 | 의미 |
|---|---|---|
| `~a` | `~mincol,colinc,minpad,padchar` / `@`=오른쪽 맞춤 | Aesthetic(CL의 `princ`. 문자열은 따옴표 없이). 인수는 어떤 타입이든 된다 |
| `~s` | 위와 같음 | Standard(CL의 `prin1`. 다시 읽을 수 있는 형태). 인수는 어떤 타입이든 된다 |
| `~w` | — | CL의 `write`. `*print-pretty*`가 참이면 프리티 프린트, 아니면 `~s`와 같다 |
| `~d` `~b` `~o` `~x` | `~mincol,padchar,commachar,interval` / `:`=자릿수 묶기, `@`=항상 부호 | 10진/2진/8진/16진 정수. 인수는 정수 |
| `~r` | `~radix,mincol,padchar,commachar,interval`(기수 있음) 또는 없음 | 기수가 있으면 그 기수(2~36). 없으면 `~r`=영어 기수사, `~:r`=영어 서수사, `~@r`=로마 숫자, `~:@r`=옛 로마 숫자. 인수는 정수 |
| `~p` | `:`=하나 되돌아가기, `@`=y/ies | 복수형(`~p`→"s", `~@p`→"y"/"ies"). 인수는 정수 |
| `~c` | `:`=이름, `@`=`#\` 구문 | 문자. 인수는 `char` |
| `~f` | `~w,d,k,overflowchar,padchar` / `@`=부호 | 고정 소수점. 인수는 수 |
| `~e` | `~w,d,,,,padchar,exptchar` / `@`=부호 | 지수 표기. 인수는 수. CL의 지수 자릿수, 스케일, overflowchar 매개변수는 지원하지 않는다(주면 오류) |
| `~g` | `@`=부호 | 일반 부동소수점. 인수는 수. 매개변수를 받지 않는다 |
| `~$` | `~d,n,w,padchar` / `:`,`@` | 통화 표기. 인수는 수 |

## 3. 출력(인수를 소비하지 않음)

| 지시자 | 의미 |
|---|---|
| `~%` | 줄바꿈(`~n%`로 n개) |
| `~&` | fresh-line(줄 맨 앞이 아니면 줄바꿈. `~n&`) |
| `~\|` | 페이지 나누기(폼 피드) |
| `~~` | 리터럴 `~`(`~n~`로 n개) |
| `~t` | 탭(`~colnum,colincT`. 이미 colnum 열 이상이면 colinc의 배수만큼 나아간다. colinc가 0이면 움직이지 않는다. `@`=상대. `:`=논리 블록 시작 기준의 탭으로, 프리티 프린트 때만 동작한다) |
| `~_` | 조건부 줄바꿈(pretty. 그냥=`:linear` / `~:_`=`:fill` / `~@_`=`:miser` / `~:@_`=`:mandatory`) |
| `~i` | 들여쓰기(pretty. `~ni`=블록 시작 + n / `~n:i`=현재 열 + n) |
| `~<newline>` | 줄바꿈을 무시한다(`:`=공백을 남긴다, `@`=줄바꿈을 남긴다) |

CL과 마찬가지로 프리티 프린터의 지시자(`~_` `~i` `~:t` `~<...~:>`, 그리고 `~a`/`~s`/`~w`의 프리티 프린트 경로)는
`*print-pretty*`가 거짓이면 모두 아무것도 하지 않는다. 기본값은 거짓이다.

## 4. 제어 구조

| 지시자 | 의미 |
|---|---|
| `~(...~)` | 대소문자 변환(`~(` 소문자, `~:(` 각 단어의 첫 글자를 대문자, `~@(` 첫 단어만 첫 글자를 대문자, `~:@(` 모두 대문자) |
| `~[...~;...~]` | 조건 선택(정수 인수로 분기. `~n[`, `~v[`, `~#[`이면 그 값으로 분기하고 인수를 받지 않는다. `~:;`=기본 절, 마지막 절에서만). `~:[거짓~;참~]`은 `bool` 인수로 분기하며 절은 정확히 두 개 |
| `~{...~}` | 반복(리스트 인수를 순회한다. `~:{`=하위 리스트마다, `~@{`=남은 인수에 대해, `~:@{`=남은 인수 중 각 리스트에 대해, `~^`=빠져나가기, `~:}`=비어 있어도 한 번 실행). 한 번의 반복에서 인수를 하나도 소비하지 않는 본체는 오류(끝나지 않는다) |
| `~<...~;...~>` | 맞춤(세그먼트를 `~mincol` 열에 펼친다. `:`/`@`=양 끝에 채우기) |
| `~<...~;...~:>` | **논리 블록**(`~:>`로 닫는다. 위의 맞춤과는 다른 것). 첫 세그먼트는 접두사, 마지막은 접미사(둘 다 리터럴 문자열만). `~@;` 구분자를 쓰면 접두사는 **줄마다의 접두사**가 된다. `~:<`는 접두사/접미사의 기본값을 `(`/`)`로 한다. 인수는 리스트 하나(`~@<`는 남은 인수를 그 자리에서 쓴다) |
| `~*` | 인수 건너뛰기(`~n*`=앞으로 n, `~:*`=뒤로, `~@*`=절대 위치로) |
| `~/name/` | 함수·메서드 호출(5장. `:`/`@` 플래그가 호출 대상에 전달된다. 매개변수는 받지 않는다) |

다음 CL 지시자는 지원하지 않는다(검사 시 오류).

- `~?`와 `~@?`: 제어 문자열을 실행 시의 인수로 받으므로, 그 지시자가 소비하는 인수를 검사할 수 없다. 그 지시자를 제어
  문자열에 직접 쓴다.
- `~@[...~]`: 인수가 nil이 아닌지 검사하지만 이 언어에는 nil이 없다. `bool`로 분기하는 `~:[거짓~;참~]`을 쓴다.
- 본체가 빈 `~{~}`: 본체를 실행 시의 인수에서 가져온다. 지시자를 중괄호 안에 쓴다.

## 5. `~/name/`

`~/name/`은 그 자리에 `(name 인수 colon at)`이라고 쓴 호출과 같은 규칙으로 `name`을 해석하고, 호출한 결과의
문자열을 출력한다. 인수를 하나 소비한다. `colon`·`at`은 지시자에 `:`·`@`가 붙어 있는지를 나타내는 `bool`이다.

```lisp
(defstruct point (x i32) (y i32))
(impl point
  (brief (self (colon bool) (at bool)) string
    (if colon (format false "<~a,~a>" self::x self::y) (format false "~a/~a" self::x self::y))))
(defun yen ((n int) (colon bool) (at bool)) string
  (format false "~a yen" n))

(println "~a" (format false "~/brief/"  (make-instance 'point :x 3 :y 4)))   ; => 3/4
(println "~a" (format false "~:/brief/" (make-instance 'point :x 3 :y 4)))   ; => <3,4>
(println "~a" (format false "~/yen/" 500))                                    ; => 500 yen
```

- 이름의 해석은 보통의 호출과 같다([문법 레퍼런스 3.10](../syntax.md#310-module--use--이름공간)). 인수의 타입에 메서드 `name`이 있으면
  그것을, 없으면 보이는 함수 `name`을 호출한다. 모듈의 함수는 경로로 쓸 수 있다(`~/m::shout/`).
- 호출할 수 있는 것은 typelisp로 쓴 함수나 메서드로, 인수·`colon`·`at`을 그대로 받아 `string`을 반환하는
  것이다. 내장 함수는 호출할 수 없다.
- **호출할 대상은 검사 시에 정해진다**. 검사기는 `~*`나 `~[`에 의한 이동도 고려해 그 `~/name/`에 닿을 수 있는
  인수를 모두 구하고, 각각의 타입으로 해석한다. 어느 하나라도 해석할 수 없으면 검사 시의 오류가 되며,
  닿을 수 있는 인수에 따라 호출할 대상이 둘 이상으로 갈리는 경우도 오류다. 실행 시에 이름을 찾지 않으므로
  AOT 실행 파일에서도 똑같이 동작한다.
- **`~{`·`~:{`·`~:@{`·`~<...~:>` 안에서는 쓸 수 없다**(검사 시의 오류). 리스트 인수의 요소 타입은
  `Sexpr`이며, 호출할 대상을 정하는 타입이 되지 못하기 때문이다. `~@{`는 호출의 나머지 인수를 돌기 때문에
  타입을 알 수 있어 쓸 수 있다.

CL과의 차이: CL은 이름을 전역 함수로 찾는다. 여기서는 호출과 같은 해석이므로 인수 타입의 메서드가 같은 이름의
함수보다 먼저 선택된다.
