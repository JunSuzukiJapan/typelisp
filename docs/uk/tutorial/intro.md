# Перші кроки

Починаючи з обчислення виразів у REPL, цей розділ послідовно розглядає функції, змінні, умови, цикли,
а також списки та `Vector`. Про те, як зібрати `typl`, див. [README.md](../../../README.md).

## 1. Запуск REPL

Запущений без аргументів, `typl` переходить у REPL (інтерактивний режим). Введіть вираз після
`typl>`, і він одразу обчислюється, а його значення друкується. `:quit` виходить з REPL.

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

Далі ввід і результати REPL показано в такому вигляді.

## 2. Обчислення виразів

typelisp — це Лісп, тому вираз береться в дужки, причому **першим іде оператор або назва функції**.
Пишуть `(+ 1 2)`, а не `1 + 2`.

```
typl> (* 2 (+ 3 4))
14
typl> (+ 1 2 3 4)
10
typl> "hello"
"hello"
typl> (upcase "hello")
"HELLO"
```

Числа бувають таких видів:

- **Цілі числа** мають тип `int`. Верхньої межі їхнього розміру немає.
- **Десяткові числа** мають тип `f64`. Пишіть їх із десятковою крапкою, як-от `1.5` або `2.0`.
- Змішувати `int` і `f64` в обчисленні не можна. `(+ 1 2.0)` — це помилка типів. Для перетворення
  пишіть `(as f64 1)`.

```
typl> (* 123456789012345 123456789012345)
15241578753238669120562399025
typl> (/ 7 2)
3
typl> (/ 7.0 2.0)
3.5
```

`/` над двома цілими числами дає ціле з відкинутою дробовою частиною (він не створює дробу, як у
Common Lisp). Для остачі використовуйте `(mod 7 2)`.

Булеві значення — `true` і `false`.

```
typl> (> 3 2)
true
typl> (and (> 3 2) (< 3 2))
false
```

## 3. Визначення функцій

Функції визначаються через `defun`. **Типи аргументів і тип результату пишуться завжди.**

```lisp
(defun square ((n int)) int
  (* n n))
```

- `(n int)` означає «аргумент `n` типу `int`». Для кількох аргументів перелічіть їх:
  `((a int) (b int))`.
- `int` після списку аргументів — це тип результату.
- Значення останнього виразу в тілі — це значення, що повертає функція. `return` писати не потрібно.

```
typl> (defun square ((n int)) int (* n n))
typl> (square 12)
144
typl> (square "a")
error: <stdin>:1:9: type error: type mismatch: expected `int`, found `string`
```

Виклик з невідповідними типами повідомляється як помилка типів **до виконання**. Коли ви запускаєте
файл, одна-єдина помилка типів будь-де означає, що не виконається жоден рядок програми.

Щоб зробити аргумент необов'язковим, використовуйте `&optional`. Якщо задано типове значення,
аргумент набуває його, коли його пропущено.

```lisp
(defun greet ((name string) &optional (greeting string "Hello")) string
  (format false "~a, ~a!" greeting name))
```

```
typl> (greet "Ann")
"Hello, Ann!"
typl> (greet "Ann" "Hi")
"Hi, Ann!"
```

`false`, переданий першим аргументом `format`, означає «повернути результат як рядок замість того, щоб
друкувати його». Кожне `~a` замінюється наступним аргументом.

## 4. Змінні

Локальні змінні створюються через `let`.

```lisp
(defun sum-of-squares ((a int) (b int)) int
  (let ((aa (square a))
        (bb (square b)))
    (+ aa bb)))
```

- Тип змінної `let` береться з її початкового значення. Писати його не потрібно.
- Змінні одного `let` не можуть посилатися одна на одну. Щоб побудувати одну змінну з попередньої,
  використовуйте `let*`.

```
typl> (let* ((a 1) (b (+ a 1))) (* a b))
2
```

Щоб змінити значення змінної, використовуйте `setf`. **Присвоєння не може змінити тип змінної.**

```
typl> (let ((x 1)) (setf x "a"))
error: <stdin>:1:22: type error: type mismatch: expected `int`, found `string`
```

Глобальні змінні визначаються через `defvar`. Тут тип справді пишуть.

```lisp
(defvar (counter int) 0)
```

## 5. Умови

### if

Пишіть `(if умова вираз-then вираз-else)`. **Вираз else пропустити не можна.**

```lisp
(defun sign ((n int)) string
  (if (< n 0) "negative" "non-negative"))
```

- Умовою може бути лише вираз типу `bool`. Запис числа, як-от `(if 0 ...)`, — це помилка типів.
- Вирази then та else мають бути одного типу.

Коли в хибному випадку нічого не має відбуватися, використовуйте `when` (а для протилежного —
`unless`).

```lisp
(when (> n 100)
  (println "large")
  (println "really large"))
```

### cond

Коли умов три й більше, `cond` читається краще. Фінальний `else` вибирається, коли жодна з умов не
виконується.

```lisp
(defun describe-number ((n int)) string
  (cond ((< n 0) "negative")
        ((= n 0) "zero")
        ((< n 10) "small")
        (else "large")))
```

### match

Щоб розгалужуватися за формою значення, використовуйте `match`.

```lisp
(defun day-name ((d int)) string
  (match d
    (0 "Sun")
    (6 "Sat")
    (_ "weekday")))
```

`_` відповідає будь-якому значенню. Оскільки в `int` незліченна кількість значень, пропуск гілки `_` —
це помилка з повідомленням, що не всі випадки охоплено. Справжня сила `match` — у розборі `Option` і
типів, які ви визначаєте самі; про них ідеться в наступному розділі, [Основи типів](types.md).

## 6. Цикли

Функція може викликати саму себе.

```lisp
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))
```

```
typl> (fact 30)
265252859812191058636308480000000
```

Для фіксованої кількості повторень використовуйте `dotimes`. `i` пробігає від 0 до `n - 1`.

```lisp
(defun sum-to ((n int)) int
  (let ((total 0))
    (dotimes (i (+ n 1))
      (setf total (+ total i)))
    total))
```

```
typl> (sum-to 100)
5050
```

Є також `while`, `do` і розширений `loop` з Common Lisp. Слова-клаузи розширеного `loop` пишуться як
ключові слова (`:for`, `:collect` тощо).

```
typl> (loop :for i :from 1 :to 5 :collect (* i i))
#<vector<int> 1 4 9 16 25>
```

## 7. Списки та Vector

### Vector

Щоб зберігати послідовність значень одного типу, використовуйте `Vector<T>`. `T` — тип елемента.

```lisp
(let ((v (the Vector<int> (Vector::new))))
  (push v 3)
  (push v 1)
  (push v 2)
  (println "~a" v))
;; prints #<vector<int> 3 1 2>
```

- Самого `(Vector::new)` недостатньо, щоб визначити тип елемента, тож задайте тип через
  `(the Vector<int> ...)`.
- `(push v x)` додає в кінець, `(get v i)` читає елемент `i`, а `(len v)` дає довжину.
- `get` з індексом поза межами зупиняє програму з помилкою.

### lambda та функції вищого порядку

Анонімні функції створюються через `lambda`. Як і в `defun`, пишуться типи аргументів і результату.

```
typl> ((lambda ((x int)) int (* x 2)) 21)
42
```

`map`, `filter`, `sort`, `foldl` та інші приймають `Vector`, перетворений на **ітератор** через
`(iter v)`. Спочатку йде колекція, потім функція. `v` у наступному прикладі — це `Vector` із `3 1 2`,
побудований вище.

```lisp
(map (iter v) (lambda ((x int)) int (* x 10)))                 ; => #<vector<int> 30 10 20>
(filter (iter v) (lambda ((x int)) bool (> x 1)))              ; => #<vector<int> 3 2>
(sort (iter v) (lambda ((a int) (b int)) bool (< a b)))        ; => #<vector<int> 1 2 3>
(foldl (iter v) (lambda ((acc int) (x int)) int (+ acc x)) 0)  ; => 6
```

Щоб обробляти елементи по одному, використовуйте `doiter`.

```lisp
(doiter (x (iter v))
  (println "item ~a" x))
```

Функція, що приймає функцію як аргумент, записує тип цього аргументу як
`(fn (типи-аргументів...) тип-результату)`. Функцію, визначену через `defun`, можна передати за її
назвою як значення.

```lisp
(defun twice ((f (fn (int) int)) (x int)) int
  (f (f x)))

(twice square 3)                                ; => 81
(twice (lambda ((x int)) int (* x 3)) 2)        ; => 18
```

### Списки (S-вирази)

Списки, створені через `'(1 2 3)` або `(list 1 2 3)`, — це **дані у вигляді S-виразів**. Їхні елементи
не мусять мати спільний тип.

```
typl> '(1 2 3)
(1 2 3)
typl> (list 1 "two" 'three)
(1 "two" three)
```

Дані у вигляді S-виразів призначені насамперед для роботи з самими програмами: в макросах
([Макроси](macros.md)) і з `read`. Для даних, елементи яких мають відомий тип, використовуйте
`Vector<T>`. Список S-виразів можна обійти через `dolist`.

```lisp
(dolist (x '(1 2 3))
  (println "x=~a" x))
```

Пара двох значень створюється через `cons` і розбирається через `car` та `cdr`.

```
typl> (let ((p (cons "age" 42))) (cdr p))
42
```

## 8. Програма у файлі

Програму можна записати у файл (з розширенням `.typl`) і запустити через `typl ім'я-файлу`.
Для виведення результатів використовуйте `println`.

```lisp
;; hello.typl
(defun fact ((n int)) int
  (if (= n 0) 1 (* n (fact (- n 1)))))

(dotimes (i 5)
  (println "~a! = ~a" i (fact i)))
```

```sh
$ typl hello.typl
0! = 1
1! = 1
2! = 2
3! = 6
4! = 24
```

- `println` друкує з тими самими директивами, що й `format`, і завершує рядок переводом рядка. `print`
  переводу рядка не додає.
- `~a` вставляє значення в зручній для читання людиною формі, а `~s` — у формі, яку можна прочитати
  назад (рядки отримують свої `"`).
- Файл читається згори донизу. **Функцію не можна викликати до її визначення.**
