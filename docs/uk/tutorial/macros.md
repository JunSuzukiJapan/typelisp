# Макроси

Макрос — це функція, що приймає програму й повертає програму. Макроси дозволяють створювати новий
синтаксис, який функції виразити не можуть. Макроси typelisp працюють так само, як `defmacro` у Common
Lisp. Цей розділ припускає, що ви прочитали «Списки (S-вирази)» у розділі [Перші кроки](intro.md).

## 1. Чим макроси відрізняються від функцій

Функція отримує свої аргументи **після їх обчислення**. Макрос отримує їх **як вирази, до обчислення**
(як дані у вигляді S-виразів), будує інший вираз і повертає його. Повернений вираз замінює виклик
макроса, і лише після цього проходить перевірку типів і виконується. Ця заміна називається
**розгортанням**.

Наприклад, синтаксис на кшталт `unless` не можна написати як функцію. Для функції тіло обчислювалося б
першим, навіть коли умова істинна.

## 2. `defmacro` і квазіцитування

Створимо `my-unless`, що виконує своє тіло лише тоді, коли умова хибна.

```lisp
(defmacro my-unless (test &rest body)
  `(if ,test () (progn ,@body ())))
```

- Аргументи макроса записуються без типів. Кожен аргумент — це дані у вигляді S-виразів.
- `&rest body` отримує решту аргументів разом як один список.
- Вираз, що починається з `` ` `` (квазіцитування), будується як дані, точно як записано. Усередині нього:
  - `,test` вставляє вміст змінної `test` у цю позицію.
  - `,@body` вставляє в цю позицію елементи списку `body`.

```lisp
(my-unless (> 1 2)
  (println "one")
  (println "two"))
;; one
;; two
```

Розгортання можна перевірити через `macroexpand-1`. Коли пишете макрос, найшвидше рухатися вперед,
спершу дивлячись на його розгортання.

```
typl> (macroexpand-1 '(my-unless (> 1 2) (println "one")))
(ok (if (> 1 2) () (progn (println "one") ())))
```

## 3. Розгортання теж перевіряються за типами

Вираз, який повертає макрос, проходить перевірку типів так само, як будь-який вираз, написаний
вручну.

```
typl> (defmacro add-a (x) `(+ ,x "a"))
typl> (add-a 1)
error: <stdin>:1:1: type error: type mismatch: expected `int`, found `string`
```

Помилка повідомляється в місці, де викликано макрос.

Правила, що гілку else в `if` пропустити не можна і що обидві гілки `if` мають бути одного типу,
застосовуються до розгортань як є. Наведений вище `my-unless` закінчується на
`(progn ,@body ())`, щоб за будь-якого типу останнього виразу тіла обидві гілки `if` мали тип `()`.

## 4. Конфлікти імен і `gensym`

Пряма реалізація макроса, що міняє місцями значення двох змінних, виглядає так:

```lisp
(defmacro swap-bad (a b)
  `(let ((tmp ,a))
     (setf ,a ,b)
     (setf ,b tmp)))
```

Здебільшого вона працює, але ламається, коли змінна викликача випадково називається `tmp`.

```lisp
(let ((tmp 1) (other 2))
  (swap-bad tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=1 other=2   (not swapped)
```

Розгортання — це `(let ((tmp tmp)) (setf tmp other) (setf other tmp))`, і створена макросом `tmp`
затуляє `tmp` викликача.

Щоб цього уникнути, створюйте імена змінних, які використовуються всередині макроса, через `gensym`.
`gensym` повертає новий символ, який неможливо записати ніде в програмі.

```lisp
(defmacro swap (a b)
  (let ((tmp (gensym "tmp")))
    `(let ((,tmp ,a))
       (setf ,a ,b)
       (setf ,b ,tmp))))
```

```lisp
(let ((tmp 1) (other 2))
  (swap tmp other)
  (println "tmp=~a other=~a" tmp other))
;; tmp=2 other=1
```

Як і в Common Lisp, макроси typelisp не запобігають конфліктам імен автоматично (вони негігієнічні).
Запам'ятайте: **використовуйте `gensym` для зв'язувань, які створює макрос.**

Так само макрос, що повторює своє тіло задану кількість разів, можна написати так:

```lisp
(defmacro repeat (n &rest body)
  (let ((i (gensym "i")))
    `(dotimes (,i ,n) ,@body)))

(repeat 3 (println "hi"))
```

## 5. Різне розгортання залежно від аргументів

Тіло макроса — це звичайний код typelisp, тому воно може досліджувати свої аргументи через `if` чи
`match` і будувати різні розгортання. Аргументи — це дані у вигляді S-виразів (`Option<Sexpr>`), а
порожній список — це `none`.

Створимо `my-and`, що повертає `true`, якщо всі його умови істинні.

```lisp
(defmacro my-and (&rest forms)
  (match forms
    ((none) 'true)                                    ; no arguments
    ((cons f more)
     (if (sexpr-null more)
         f                                            ; just one
         `(if ,f (my-and ,@more) false)))             ; two or more
    (_ (panic "my-and: not a list"))))

(my-and (> 2 1) (> 3 2))      ; => true
(my-and (> 2 1) (> 1 3))      ; => false
```

- `(cons f more)` — це візерунок, що бере голову списку в `f`, а решту в `more`.
- `sexpr-null` перевіряє, чи є дані у вигляді S-виразів порожнім списком.
- Фінальна гілка `_` потрібна, бо дані у вигляді S-виразів мають й інші форми, ніж списки (числа,
  рядки тощо), і `match` вимагає охопити також їх. Аргумент `&rest` завжди є списком, тож ця гілка
  фактично ніколи не виконується.
- Макрос може викликати сам себе у своєму розгортанні. Розгортання повторюється, доки не залишиться
  викликів макросів.

## 6. Необов'язкові аргументи

`&optional` приймає аргументи, які можна пропустити. Можна задавати типові значення.

```lisp
(defmacro inc-by (place &optional (n 1))
  `(setf ,place (+ ,place ,n)))

(let ((c 10))
  (inc-by c)
  (inc-by c 5)
  c)                            ; => 16
```

`&key` приймає іменовані аргументи
([Довідник із синтаксису 3.14](../reference/syntax.md#314-defmacro--визначення-макросів)).

## 7. `macrolet`: макроси лише для одного місця

Макрос, що використовується лише всередині одного виразу, можна визначити через `macrolet`. Зовні він
не видимий.

```lisp
(macrolet ((sq (x) `(* ,x ,x)))
  (+ (sq 3) (sq 4)))            ; => 25
```

## 8. Що слід пам'ятати

- **Макрос можна викликати лише після його визначення.** Як і з функціями, визначайте його ближче до
  початку файлу.
- Зробити макрос доступним іншим модулям можна через `(pub defmacro ...)`.
- Значна частина стандартного синтаксису, зокрема `when`, `unless`, `cond`, `and`, `or` і `dotimes`,
  визначена як макроси. Подивитися, що всередині, можна через `(macroexpand '(when true 1))`.
- Якщо щось можна написати як функцію, пишіть як функцію. Макроси не можна передавати як значення, а щоб
  зрозуміти, що вони роблять, доводиться читати їхнє розгортання.
