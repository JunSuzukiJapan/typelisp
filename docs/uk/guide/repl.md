# REPL

Якщо запустити `typl` без аргументів, відкривається REPL (інтерактивний режим). У цьому документі
описано, що вміє REPL, крім обчислення виразів: його команди, допомогу під час введення, звернення
до попередніх результатів, зупинку обчислення та розбір після помилки.

## Запуск і вихід

```
$ typl
typl> (+ 1 2)
3
typl> :quit
```

Вихід — `:quit` (коротко `:q`) або `Ctrl+D`. Історія введення зберігається в `~/.typl_history`, і
під час наступного запуску її можна викликати через `Ctrl+P` / `Ctrl+N` або `Ctrl+R` (пошук в
історії).

Під час запуску, до першого запрошення, по черзі виконується таке. Жоден із цих кроків не виводить
отримані значення.

1. Вміст `~/.typlrc`, якщо файл існує. З `--no-init` він не читається.
2. `--eval FORM` і `--load FILE` з командного рядка в тому порядку, в якому їх записано. Обидва
   можна вказувати скільки завгодно разів.

```
$ typl --load util.typl --eval '(println "ready")'
ready
typl>
```

`--eval`, `--load` і `--no-init` призначені лише для запуску REPL. Вказати їх під час запуску файлу
— помилка.

REPL починає роботу в модулі `user`. Якщо перейти до іншого модуля через `(in-module foo)`,
запрошення показує цей модуль.

```
typl> (in-module foo)
typl user::foo>
```

## Команди REPL

`:ім'я`, записане на початку рядка, — це команда REPL. `:help` виводить їхній список. `:ім'я`, якого
немає в списку, командою не є й обчислюється як звичайне ключове слово.

| Команда | Значення |
|---|---|
| `:help` (`:h`, `:?`) | вивести список команд |
| `:type FORM` (`:t`) | вивести тип FORM, не обчислюючи його |
| `:describe NAME` (`:d`) | вивести вид означення, його тип, поля або варіанти, методи, трейти, які воно реалізує, місце означення та рядок документації |
| `:apropos TEXT` | знайти в усіх модулях означення, ім'я яких містить TEXT (регістр не враховується) |
| `:src NAME` | вивести вихідний текст означення |
| `:who-calls NAME` | вивести функції та методи, які викликають функцію або метод NAME |
| `:inspect FORM` (`:i`) | обчислити FORM і розкрити значення відповідно до його типу |
| `:backtrace` (`:bt`) | вивести виклики, що виконувалися, коли попередній рядок завершився помилкою, починаючи з найвнутрішнього |
| `:locals [N]` | вивести аргументи виклику N з `:backtrace` (виклику 0, якщо N не вказано) |
| `:cd [DIR]` | змінити поточну теку на DIR (на домашню, якщо DIR не вказано) |
| `:pwd` | вивести поточну теку |
| `:quit` (`:exit`, `:q`) | вийти з REPL |

NAME може бути іменем на кшталт `inner` або шляхом на кшталт `std::seq::reverse` чи
`Option::unwrap`.

```
typl> (defun inner ((x int) (s string)) int "Додає 1 до x." (+ x 1))
typl> :describe inner
user::inner is a function
  type: (fn (int string) int)
  parameters: x s
  defined at <stdin>:1:1

Додає 1 до x.
typl> :src inner
(defun inner ((x int) (s string)) int "Додає 1 до x." (+ x 1))
```

`:src` показує означення, завантажене з файлу, за цим файлом, а означення, введене в REPL, — за
введеним текстом. Для означень стандартної бібліотеки місце у вихідному тексті не записано, тому
їхній вихідний текст показати не можна.

`:who-calls` переглядає тіла функцій поточного сеансу. Для узагальненої функції знаходяться лише
використання, конкретизовані конкретними типами.

`:cd` змінює теку, в якій шукає `(load ...)`, але `use` і далі шукає файли в теці, де було
запущено REPL.

## Розкриття значення (`:inspect`)

`:inspect` розкриває значення відповідно до його типу. Структура розкривається у свої поля,
перелічення (зокрема `Option`) — у поля свого варіанта, `Vector` — в елементи, `HashTable` — у
ключі та значення. Число переходить до цієї частини, `u` повертає на рівень вгору, `q` завершує.

```
typl> (defstruct point (x int) (y Option<int>))
typl> :inspect (make-instance 'point :x 1 :y (Some 2))
(make-instance 'point :x 1 :y (Some 2)) = #<point x: 1 y: (Some 2)>
  type: point
  0. x = 1
  1. y = (Some 2)
inspect> 1
y = (Some 2)
  type: Option<int>
  0. Some 0 = 2
inspect> q
```

Списки та `Sexpr` не розкриваються, а виводяться як є.

## Допомога під час введення

Під час введення в терміналі доступне таке.

- `Tab` доповнює імена (означення та синтаксис на кшталт `if` і `defun`), шляхи з `::`, команди REPL
  на початку рядка, а всередині рядкового літерала — імена файлів.
- Якщо після імені функції ввести пробіл, у кінці рядка блідим кольором показується тип цієї
  функції.
- Дужка, парна до дужки поруч із курсором, підсвічується.
- Якщо натиснути Enter до завершення форми, наступний рядок починається з відступом за кількістю
  відкритих дужок.

## Попередні результати (`:*`, `:**`, `:***`)

У REPL `:*` — останнє виведене значення, `:**` — попереднє, `:***` — ще на одне раніше. Кожне має
тип свого значення.

```
typl> 1
1
typl> "a"
"a"
typl> 2
2
typl> (+ :*** :*)
3
```

- Введення, яке не вивело значення (наприклад, означення) або завершилося помилкою, не зсуває
  результати.
- Написати `:**` або `:***`, поки стільки результатів ще немає, — помилка.
- Процитоване `':*` — звичайне ключове слово.
- `:*`, записане в тілі функції, і далі вказує на результат на момент означення функції. `*` у
  Common Lisp читає значення в момент виклику, а typelisp фіксує його під час означення, щоб воно
  мало тип.
- Поза REPL (під час запуску файлу, а також у `~/.typlrc`, `--load` і `--eval`) `:*` — звичайне
  ключове слово.

## Зупинка обчислення (`Ctrl+C`)

Натискання `Ctrl+C` під час обчислення зупиняє його й повертає до запрошення. Усе, що було означено
раніше, зберігається. Це працює і для циклу в інтерпретаторі, і для циклу в скомпільованому коді,
і під час очікування в `sleep` або `wait`. Очищення у виконуваних `unwind-protect` виконується.

```
typl> (loop)
^Cerror: interrupted
typl>
```

`Ctrl+C`, натиснуте під час введення, лише відкидає рядок, що вводиться.

## Розбір після помилки (`:backtrace`, `:locals`)

Після того як обчислення зупинилося з помилкою, `:backtrace` (`:bt`) виводить виклики функцій, що
виконувалися в той момент, починаючи з найвнутрішнього. `:locals N` виводить аргументи виклику N
відповідно до їхніх оголошених типів.

```
typl> (defun inner ((x int)) int (if (= x 0) (panic "boom") x))
typl> (defun outer ((n int)) int (* 2 (inner n)))
typl> (outer 0)
error: <stdin>:1:40: panic: boom
typl> :bt
  0: (user::inner 0)  called at <stdin>:1:33
  1: (user::outer 0)  called at <stdin>:1:1
typl> :locals 1
  n = 0
```

- Для виклику з останнього виразу функції (хвостового виклику) функція, що викликає, не
  показується. Завдяки цьому цикл із хвостовою рекурсією займає місце одного виклику, скільки б
  разів він не повторювався.
- Виклики всередині скомпільованих функцій та анонімні функції (`lambda`) не показуються.
- `:locals` показує лише аргументи, а не змінні, зв'язані через `let`.
- Під час обчислення наступного рядка запис про попередню помилку видаляється.
