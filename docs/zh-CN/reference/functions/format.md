# 格式指令

写在 `print`/`println`/`format` 的控制字符串中的指令。几乎涵盖了 CL 的全部 `format` 指令。函数本身的说明见
[打印](printing.md#1-print--println--format)。

## 1. 写法

每个指令依次由 `~`、可选的**前缀参数**（逗号分隔。整数 / `'c`（字符）/ `v`（从下一个参数取）/ `#`（剩余参数的个数））、
可选的**修饰符** `:`・`@`、指令字符组成。指令字符不区分大小写。

控制字符串必须是字面量（[打印](printing.md#1-print--println--format)）。在此基础上，检查时会检查以下内容。

- **参数的个数和类型。** 对每个消耗参数的指令，检查是否还有参数、类型是否被接受（下表的"参数"说明）。在由运行时的值决定
  路径的地方——`~*` 的移动、`~[` 的哪个子句、`~^` 是否生效、`~@{` 的重复次数——会检查**所有路径**。参数多余没有关系
  （与 CL 相同）。
- **参数与修饰符。** 不接受的修饰符、过多的参数、超出范围的值（负的宽度、2〜36 以外的基数、在取字符的位置写整数等）都是
  错误。不会静默忽略或舍入。

列表参数（`~{`・`~:{`・`~<...~:>`）的**元素**是 `Sexpr`，个数和每个元素的类型都无法从类型得知。对元素的要求（`~d` 需要
整数等）和元素不足，在值到达时检查，是运行时错误（不会切换到别的显示方式）。

不采用 CL 的宽松规则。给 `~d` 传入非整数时按 `~a` 显示、`~:[` 把任意值当作真假处理之类的改读都不做，而是类型错误。

## 2. 输出（消耗一个参数）

| 指令 | 参数 / 修饰符 | 含义 |
|---|---|---|
| `~a` | `~mincol,colinc,minpad,padchar` / `@`=右对齐 | aesthetic（CL 的 `princ`。字符串不带引号）。参数可以是任何类型 |
| `~s` | 同上 | standard（CL 的 `prin1`。可读回的表示）。参数可以是任何类型 |
| `~w` | — | CL 的 `write`。`*print-pretty*` 为真时美化输出，为假时与 `~s` 相同 |
| `~d` `~b` `~o` `~x` | `~mincol,padchar,commachar,interval` / `:`=分组, `@`=总带符号 | 十／二／八／十六进制整数。参数是整数 |
| `~r` | `~radix,mincol,padchar,commachar,interval`（指定基数）或不指定 | 指定基数时为该进制（基数 2〜36）。不指定时 `~r`=英语基数词、`~:r`=英语序数词、`~@r`=罗马数字、`~:@r`=旧式罗马数字。参数是整数 |
| `~p` | `:`=回退一个, `@`=y/ies | 复数形式（`~p`→"s"、`~@p`→"y"/"ies"）。参数是整数 |
| `~c` | `:`=名称, `@`=`#\` 语法 | 字符。参数是 `char` |
| `~f` | `~w,d,k,overflowchar,padchar` / `@`=符号 | 定点数。参数是数 |
| `~e` | `~w,d,,,,padchar,exptchar` / `@`=符号 | 指数记法。参数是数。不支持 CL 的 exponent-digits、scale、overflowchar 参数（指定时是错误） |
| `~g` | `@`=符号 | 通用浮点。参数是数。不接受参数 |
| `~$` | `~d,n,w,padchar` / `:`,`@` | 货币记法。参数是数 |

## 3. 输出（不消耗参数）

| 指令 | 含义 |
|---|---|
| `~%` | 换行（`~n%` 为 n 个） |
| `~&` | fresh-line（不在行首时换行。`~n&`） |
| `~\|` | 换页（form feed） |
| `~~` | 字面量 `~`（`~n~` 为 n 个） |
| `~t` | 制表（`~colnum,colincT`。已经在 colnum 列以后时前进 colinc 的倍数。colinc 为 0 时不前进。`@`=相对。`:`=以逻辑块起点为基准的制表，只在 pretty 时起作用） |
| `~_` | 条件换行（pretty。无修饰=`:linear` / `~:_`=`:fill` / `~@_`=`:miser` / `~:@_`=`:mandatory`） |
| `~i` | 缩进（pretty。`~ni`=块起点+n / `~n:i`=当前列+n） |
| `~<换行>` | 忽略换行（`:`=保留空白, `@`=保留换行） |

与 CL 一样，pretty printer 类的指令（`~_` `~i` `~:t` `~<...~:>`，以及 `~a`/`~s`/`~w` 的美化路径）在 `*print-pretty*`
为假时全部不起作用。默认为假。

## 4. 控制结构

| 指令 | 含义 |
|---|---|
| `~(...~)` | 大小写转换（`~(` 小写, `~:(` 每个词首字母大写, `~@(` 只有首字母大写, `~:@(` 全部大写） |
| `~[...~;...~]` | 条件选择（按整数参数分支。`~n[`・`~v[`・`~#[` 按该值分支，不取参数。`~:;`=默认子句，只能是最后一个子句）。`~:[假~;真~]` 按 `bool` 参数分支，子句恰好 2 个 |
| `~{...~}` | 迭代（遍历列表参数。`~:{`=每个子列表, `~@{`=剩余参数, `~:@{`=剩余参数中的每个列表, `~^`=退出, `~:}`=即使为空也执行 1 次）。一次迭代中一个参数都不消耗的主体是错误（不会结束） |
| `~<...~;...~>` | 对齐（把各段分布到 `~mincol` 宽度。`:`/`@`=两端的填充） |
| `~<...~;...~:>` | **逻辑块**（以 `~:>` 结束。与上面的对齐是不同的东西）。第一段=prefix，最后一段=suffix（都只能是字面量字符串）。用 `~@;` 分隔时 prefix 是**行首 prefix**。`~:<` 把 prefix/suffix 默认为 `(`/`)`。参数是一个列表（`~@<` 就地使用剩余参数） |
| `~*` | 跳过参数（`~n*`=前进 n 个, `~:*`=回退, `~@*`=跳到绝对位置） |
| `~/name/` | 方法调用（第 5 章。`:`/`@` 标志传给方法。不接受参数） |

不支持 CL 的以下指令（检查时的错误）。

- `~?`・`~@?`：把控制字符串作为运行时的参数接收，无法检查其中指令消耗的参数。请把这些指令直接写进控制字符串。
- `~@[...~]`：检查参数是否不为 nil，但本语言没有 nil。请使用按 `bool` 分支的 `~:[假~;真~]`。
- 主体为空的 `~{~}`：从运行时的参数取主体。请把指令写在括号里面。

## 5. `~/name/`

**与 CL 有一点不同：名字不是作为全局函数查找，而是作为参数自身类型的方法查找。** 方法的形式为
`((self Self) (colon bool) (at bool)) → string`，指令的 `:`/`@` 原样传入。

CL 那种作为全局函数查找的方式在本语言中无法安全实现。即使控制字符串是字面量，列表参数的元素（`~{` 内部）是什么类型在检查时
也无法确定，只按名字查找就可能调用到给别的类型准备的函数。按值的类型选择，该方法正是针对该类型经过类型检查的，所以是安全的
（与 `print-object` 是同一机制）。它也可以用于 `string`/`bool`/`char`/`symbol`/列表之类的值。只有整数无法从值区分宽度，
所以**只在多个整数类型定义了同名方法时**才是错误。

无法确定作用于哪个参数，但可以确定可能调用哪些方法。检查器从字面量的控制字符串中收集所有 `~/name/`，记录该调用处的参数类型中
具有上述形式方法的那些。因此，**如果没有任何参数的类型具有该方法，就是检查时的错误**（而不是运行时），在 AOT 可执行文件中
也能工作。

```lisp
(defstruct point (x i32) (y i32))
(defmethod brief ((self point) (colon bool) (at bool)) string
  (if colon (format false "<~a,~a>" self::x self::y) (format false "~a/~a" self::x self::y)))
(println "~a" (format false "~/brief/"  (point::new 3 4)))   ; => 3/4
(println "~a" (format false "~:/brief/" (point::new 3 4)))   ; => <3,4>
```
